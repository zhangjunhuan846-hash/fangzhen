# EIS合成电路演示

`synthetic_1rc.csv` 是解析公式生成的合成谱，用于工作站软件验收：

```text
Z(f) = 0.012 + 0.055 / (1 + j*2*pi*f*0.055*120)
R0 = 0.012 Ω, R1 = 0.055 Ω, C1 = 120 F
f(i) = 10**(-4 + i/10) Hz, i = 0…80
```

没有加入测量噪声，不代表任何实际电芯。生成公式独立于 impedance.py 的正向计算实现。

双击项目根目录 `启动科研工作站.bat` → “论文方法 / EIS校准” → 选择这个 CSV → 频率选 Hz、阻抗选 Ω，保留原始虚部符号 → “运行Lin-KK与RC拟合”。选择 1RC 与默认固定网格策略。

可核对恢复的 R0/R1/C1、输入谱与拟合谱叠图，下载逐点结果与参数。自动 μ 截止是另一种阶数策略，在宽频带理想谱上也可能提前停止；阈值超出本身不是测量无效的证明。
