# Gate 5.5（第一步）— 测量 → 模型尺度：来源审计

> **本步不做任何优化。** 只回答一个问题：**Chen2020 里的 `Positive particle radius` = 5.22 µm
> 究竟代表什么、来自什么测量、以及它和你手上的 D10/D50/D90 能不能对得上。**
>
> 这一步的结论决定后面真实石墨实验**该怎么测、测出来的数怎么喂进模型**。
>
> **结论（先说）**：
> ① Chen2020 的 5.22 µm 是 **SEM 二维图像 + ImageJ 的“数量加权平均半径”**，
>    假设球形，**不是**激光衍射、**不是** D50；
> ② 它的**平均直径 ≈ 10.44 µm ≈ 你测的 D10 = 10.72 µm** —— 两者对得上，
>    但**不是因为 D10 是“正确统计量”**，而是因为**数量加权均值天然接近小分位**；
> ③ **它的扩散系数 `D_s` 本身就是 apparent 值**（GITT + Sand 方程），不是本征材料常数；
> ④ **因此 `(D_s, R_p)` 这一对在参数集里从来就不是一对“物理一致”的数** ——
>    它们来自**两套互不相干的测量**，$\tau_d=R_p^2/D_s$ 这个组合**没有任何一个实验直接约束过**。
>    这才是 G5.3/G5.4 里那条长脊的**根因**。

## 1. 出处

`pybamm.ParameterValues("Chen2020")` 的**唯一**来源是模块级引用：

> Chang-Hui Chen, Ferran Brosa Planella, Kieran O'Regan, Dominika Gastol,
> W. Dhammika Widanage, Emma Kendrick.
> *"Development of Experimental Techniques for Parameterization of Multi-scale
> Lithium-ion Battery Models."* **J. Electrochem. Soc. 167 (2020) 080534.**
> DOI: `10.1149/1945-7111/ab9050`（开放获取 CC BY-NC-ND）

电芯：**商用 21700 LGM50**；正极 **NMC 811**；负极 **Graphite-SiOx 双组分**。

**审计发现（可复现）**：

```python
pv = pybamm.ParameterValues("Chen2020")
# pv 上没有 citation / doi / source / notes / comments 任何一个属性
pv["Positive particle radius [m]"]      # 5.22e-06   <- 裸字面量
```

参数文件 `pybamm/input/parameters/lithium_ion/Chen2020.py` 里该行就是
`"Positive particle radius [m]": 5.22e-06,` ——
**整个参数集没有任何逐参数来源说明**，要问“这个数怎么来的”只能回去读论文。

> **这本身是一条结论**：**参数集层面的 provenance 是缺失的。**
> 平台自己讲 provenance/auditability，但对第三方参数集无能为力 ——
> 所以必须把来源审计**外置**成文档（就是本文），否则以后没人能回答这个问题。

## 2. 粒径怎么测的

论文原文（Physical properties 部分）：

> *"The morphologies of both the negative and positive electrodes were studied using
> **SEM**. The average particle size was ascertained from analyzing SEM images and
> **measuring all the particle sizes observed in a 2D top-down image (ImageJ)**."*

> *"The particles are assumed to be **spherical** in the analysis..."*

> *"**The average particle radii** for NMC, graphite and silicon are **5.22**, 5.86 and
> 1.52 µm respectively."*

| 项 | 内容 |
|---|---|
| 仪器 | **SEM 二维俯视图** |
| 分析 | ImageJ，测量图中**所有**可分辨颗粒 |
| 统计量 | **平均半径**（数量加权，number-weighted mean） |
| 形状假设 | **球形** |
| 报告值 | **5.22 µm（半径）** → 平均直径 ≈ **10.44 µm** |
| **未报告** | **D10 / D50 / D90、中位数、体积加权分布** |
| **未使用** | 激光衍射；BET 只用于孔径/孔隙率，**不是**粒径来源 |
| FIB-SEM | 用于 3D 微结构重构（孔隙率/曲折度），**不是**粒径统计来源 |

**关键**：**5.22 µm 是“半径”**。论文 Table II 的列标题写作 *"Average particle size"*，
存在用词不统一；但 Table V 明确写 *"Particle radius … NMC 5.22"*，全文一致按**半径**使用。

## 3. 扩散系数怎么来的（这一条最容易被忽略）

> *"The solid phase diffusion coefficients (or diffusivities) in the electrode materials
> are determined by **GITT** at different states of lithiation from half cell measurements."*

> *"...the **apparent** diffusion coefficients calculated using the **Sand equation**."*

脉冲条件：**C/10，每次 2.5 min**，随后松弛至 OCV；对电压瞬态按 $U \propto t^{1/2}$
线性化后拟合系数反推 $D$。

Table V（NMC 正极）：

| 电位 (V) | 脉冲电流 (mA, 0.1C) | 脉冲时长 | **粒子半径** | **$D_s$ ($10^{-15}$ m²/s)** |
|---|---|---|---|---|
| 3.66–4.25 | 0.73 | 2.5 min | **5.22 µm** | **1.48 ± 1.05** |

> ⚠️ **注意两处**
>
> ① **论文的 $D_s$ 是 1.48e-15，而 PyBaMM Chen2020 里是 4e-15** —— 相差 **2.7 倍**。
>    PyBaMM 版本与该论文数值**不一致**（很可能是为整电芯拟合重调过）。
>    **引用时必须区分“Chen2020 论文值”与“PyBaMM Chen2020 参数集值”。**
>
> ② **论文自己写明这是 apparent / effective 值**，且论文给出的四条假设里第二条是：
>
> > *"There is **one particle size radius and not a particle size distribution**."*
>
>    并且明确知道这会引入误差：
>
> > *"For the positive electrode the particles are spherical, therefore the main source of
> > deviation from theoretical is in **the effective surface area**, which arises from
> > **the particle size distribution**, and particles not being directly in contact with
> > the electrolyte..."*
>
> > *"It should be noted, however, that in the simulations **an effective diffusion
> > coefficient is utilised**... **To use an average diffusion coefficient is a huge
> > simplification**..."*

**即：论文作者本人把这两个数都标成了 effective / apparent，并建议后续用随 SOC 变化的变扩散系数。**

## 4. **关键交叉核对**：两套数能不能对上

```
Chen2020（论文）  SEM 数量加权 *平均半径* = 5.22 µm
                 → 平均直径            = 10.44 µm

你手上的 PSD（*直径*）  D10 = 10.72 µm
                       D50 = 17.58 µm
                       D90 = 27.82 µm
```

**`10.44 µm` ≈ `D10 = 10.72 µm`（相差 2.6 %）。**

这不是巧合，而是**统计量性质**的必然结果：对典型 PSD，
**数量加权平均直径天然落在小分位附近**（大颗粒数量少但体积占比高，
一旦按体积加权，均值就会被拉向 D50 一侧）。

→ 所以 G5.4 里出现的 "$D_{10}/2$ 恰好接近真值"，**原因是它恰好复现了
Chen2020 用的是数量加权均值**，**不是**因为 $D_{10}$ 是"正确的统计量"。

> **这就把 G5.4 里那条措辞边界解释清楚了**：
> 不能写 "$D_{10}/2$ 是正确的物理映射"，
> 正确的说法是"**它恰好与生成该数据的有效尺度同量级**"。
> 真正的映射关系应该是
> $$R_p^{model} = k\,D_q$$
> 其中 $q$（哪个分位）与 $k$（几何/扩散长度定义）**都还没被论证**。

**另一条必须核实的**：你手上 D10/D50/D90 的**测量方法未知**
（激光衍射？筛分？SEM 图像分析？）以及**加权方式未知**（数量？体积？）。
激光衍射默认输出**体积加权**分布，与 Chen2020 的**数量加权 SEM 均值**不可直接比。
**这一条不确认，后面任何映射都是空中楼阁。**

## 5. 这解释了整条 G5 链的那条长脊

把第 3、4 节合起来看：

```text
R_p（5.22 µm）   来自 SEM 图像分析（数量加权均值、假设球形、固定不随 SOC 变）
D_s（4e-15）     来自 GITT + Sand 方程（apparent 值、假设单一粒径、C/10 脉冲）
                 ↑ 两者来自*两套互不相干*的实验
```

$$\tau_d=\frac{R_p^2}{D_s}$$

**这个组合没有任何一个实验直接测量过它。** 它是两个独立估计的比值。

→ **G5.3 那条伸长率 3.2–11.0 的脊，根因就在这里**：
电压曲线所约束的主要是 $\tau_d$，而 $\tau_d$ 在这份参数集里恰恰是**最没有实验依据**的那个量。
反过来，**G5.4 里"独立 $R_p$ 约束能打破退化"之所以有效，也是因为它是唯一直接锚定
这个组合里一个因子的信息。**

## 6. 下一步的实验设计（G5.5 主体）

### 6.1 先把 $R_p$ 的**不确定度传递**测出来

不需要一上来就建复杂映射。先做最直接的：

```text
R_p 固定为真值
R_p = 真值 × (1 ± 5 %)      (对应 ±0.0212 dex)
R_p = 真值 × (1 ± 10 %)     (对应 ±0.0414 dex)
R_p = 真值 × (1 ± 20 %)     (对应 ±0.0792 dex)
```

然后测：

$$R_p\ \text{的不确定度} \;\longrightarrow\; D_s\ \text{的不确定度}$$

**产出**：一张"粒径表征精度要求"曲线 ——
它直接回答**以后石墨实验的粒径表征要做到什么精度，$D_s$ 才能稳定识别**。
这比"再优化一个参数"有用得多。

### 6.2 然后才是 $k$ 与 $q$

$$R_p^{model}=k\,D_q,\qquad q\in\{D_{10},D_{50},D_{90},\dots\},\quad k\in[\text{几何/扩散长度定义}]$$

两个因子**都带不确定度**，一起传播。

### 6.3 必须先确认的三件事（否则映射无从谈起）

| 待确认 | 为什么 |
|---|---|
| 你的 PSD 是**什么仪器**测的 | 激光衍射 / 筛分 / SEM 图像分析 —— 分布定义不同 |
| **加权方式**（数量 / 体积 / 强度） | 与 Chen2020 的数量加权 SEM 均值不可直接比 |
| 是 **diameter 还是 radius** | 差 2 倍，最常见的低级错误 |
| 你测的是**什么**颗粒 | primary particle / secondary agglomerate / 复合颗粒 —— 石墨尤其 |

## 7. 边界

- 本节是**文献与参数集审计**，**不含任何新计算**。所有引文来自 Chen 等 2020 开放获取版。
- **论文值 1.48e-15 与 PyBaMM 值 4e-15 的差异原因未查明**（推测为整电芯重拟合，
  **这是推测，不是结论**）。
- 你手上 PSD 的仪器、加权方式、颗粒定义**均未确认**，第 4 节的交叉核对
  **只在“它是直径”这一条上成立**。
- 5.22 µm 与 D10 的接近**是量级一致，不是等同**；**不得**据此把 $R_p$ 设为 $D_{10}/2$。
