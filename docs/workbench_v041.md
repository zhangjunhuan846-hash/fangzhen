# Fangzhen v0.4.1：项目工作区与预测

## 启动

在 Windows 的仓库根目录双击 [启动科研工作站.bat](../启动科研工作站.bat)，或在 Python 3.11 及以上环境运行：

```powershell
python -m pip install numpy
python -m user_tools.research_workbench
```

启动后会打开浏览器。服务默认绑定 `127.0.0.1`，启动地址包含本机访问令牌，应使用程序生成的完整地址。再次启动会打开已有实例。旧版本占用同一数据目录时，先在旧页面保存并关闭，再启动新版。

上述依赖覆盖容量预测与基础工作区。PyBaMM、材料模型训练、工程仿真和环境评价各自需要已配置的科学计算环境；参见 [安装说明](../HANDOFF.md)、[工程扩展](engineering_integrations_v0312_20261029.md) 和 [环境评价](workbench_v036.md)。Windows Excel 导出另需现有文档运行时；Linux 导出使用 `openpyxl`。

## 以项目连接研究任务

1. 在「项目总览」选择或新建项目。
2. 在「数据中心」编辑表格、导入 Excel 或查看版本。追加导入会保留项目编号，跳过完全重复的行；编号相同但内容冲突时拒绝合并。
3. 在「建模与仿真」选择电化学、工程、容量或材料性能任务。
4. 在「验证与评价」检查留出数据上的结果，并在「实验反馈」记录实际实验数据。
5. 在「任务与结果」查看该项目任务、输入版本和父任务，继续验证或复用配置。

计算完成和验证通过分别记录。界面中的流程进度以当前项目的任务和实验记录为依据。

## 容量衰退预测

从「建模与仿真」进入「容量衰退预测」。数据来源支持仓库随附的公开容量表、自己的 UTF-8 CSV，或本项目已完成预测保留的原始输入。

CSV 表头为：

```csv
cell_id,cycle,capacity_Ah
cell_A,1,1.00
cell_A,2,0.99
```

页面会展示真实观测数量、循环或观测编号范围、首末容量以及数据间隔信息。原始零容量和不连续编号保留。

- 「留出数据做回测」使用早期观测训练，以后续已测容量计算 MAE、RMSE 和末次容量基线误差。
- 「全部训练后外推」使用全部已测观测。没有留出数据时，误差卡片显示空值。
- 末次实测之后的区域标为未来外推；误差带反映训练期历史预测误差的目标水平，未来实测覆盖率仍需新数据检验。
- 修改左侧配置后，右侧历史结果保留原配置；点击「运行预测并保存结果」会创建新的任务。
- 图表可用鼠标或左右方向键查看逐点值，表格和下载文件保留预测值、实测值与区间字段。
- 「复用数据与配置，再做预测」引用本项目的原始输入；服务器核对输入 SHA-256，并记录来源任务。

公开数据来源与原有可复现回测见 [钠电容量说明](sodium_capacity.md)。

## 材料性能预测

进入「材料性能预测」，先在「训练性能模型」选择输入描述符、目标和分组验证方式。训练完成后，结果页可直接选择「使用保存模型预测新样品」。

「使用已有模型预测」列出当前项目的已保存模型，显示目标、所需描述符及训练数据版本。导入包含这些描述符的新样品 CSV 后运行预测。预测结果和训练任务在「任务与结果」中关联；界面提供的合成数据仅用于软件流程检查，实际预测能力由对应实验数据和独立验证确定。

## 数据保存与托管入口

源码运行时，本机项目数据库、输入副本和运行记录位于 `data/workbench_scalar10/`。克隆 GitHub 源码会创建自己的项目库。

`user_tools.workbench.bisheng_hosted` 提供毕昇托管运行入口，使用毕昇 SDK 校验可信平台代理传入的应用身份，并使用平台数据目录。运行它需要另行配置毕昇服务端、SDK、科学计算镜像、应用代理和持久存储。当前源码发布不执行应用注册或服务端部署，也不包含运行镜像及任何部署密钥。

```powershell
node --test tests/workbench_capacity_ui.test.cjs tests/workbench_project_flow.test.cjs
```

```bash

```
