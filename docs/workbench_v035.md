本轮读取八篇论文的正文、关键算法及相关附录，归档原件/页码文本，共175页；源码对应七个仓库，固定commit或源码快照，保留LICENSE。未运行上游研究脚本，未降级PyBaMM环境。

详细证据在 `outputs/paper_study_20261012/论文与源码学习报告.html` 与 `study_ledger.json`。正文覆盖范围、缺少的补充材料、源码差异逐篇列出。程序“论文方法/EIS校准”入口可下载该报告。

## 已加入平台

### 1. 有限候选 q=1 MC-NEHVI

“下一组实验选点”可选择新版NEHVI或原固定前沿EHVI。新方法通过联合潜在函数后验，在每个样本中重建可行前沿，再计算超体积改进；保留已测点—候选的协方差。同一位置必须共享相同随机变量，不能独立抽样产生虚假增益。

两个目标独立，GP超参数固定，有限候选最多200个已测+候选点，q=1。输出MC标准误。不是官方并行qLogNEHVI，不是连续全局优化，也不声称已在回收石墨上超过随机。声明噪声必须对应所建模观测；条件均值的噪声应依据其重复实验标准误，不能直接当成单电芯标准差。

原始G5/G6、Chen留出预测失败、公开石墨历史BO比较均保留。未重新运行或替换这些结果。

### 2. EIS 谱检查与参考频域仿真

导入CSV列 `frequency_Hz,Z_real_ohm,Z_imag_ohm`，多谱可加 `spectrum_id`。明确选择Hz/rad/s、Ω/mΩ，明确虚部是否为−Im(Z)。检查有限值、正频率、重复频率；绘制Nyquist及Bode数值。原件、参数与结果保存，不自动平滑或平均。

只有谱点不能证明激励线性、工作点稳态、Kramers-Kronig一致性，因此这些状态仍未评估。面积归一阻抗不自动当Ω；需依据明确面积转换。

公开频域计算使用PyBaMM26.8原生EISSimulation，支持参考SPM/SPMe/DFN以及Chen2020或Ecker石墨半电池参数。全电池SOC与半电池x0不混用。differential表面形式需要双电层容量，输入中的0.2F/m²是公开演示假设，**不是Chen/Ecker实测值**，实际采用值写入结果。

该入口是版本适配和小信号模型探索，不是Hallemans论文18参数拟合、同样品跨SOC物理参数辨识或真实材料验证。与论文原环境24.9以及更新作者代码25.6分开标注。

### 3. Parquet 时域预处理

“一键数据预处理”支持≤20MB的Parquet；当前明确支持 `timepoints [s],voltages [V],currents [A]` 或 `time_s,voltage_V,current_A`。采用已有WSL Pandas/PyArrow环境，最多300万行且检查解码规模。

生成完整标准化CSV、原行号、时间段、异常数量、Command目录与概览抽样曲线。保留原件与SHA。该路径不使用CSV手动单位覆盖，不修复时间回跳、不插值。图用于概览，完整原始信号用于后续物理分析。

已实际读取MJ1放电Parquet的1,576,231行。这是GITT/EIS测量过程的**时域波形**，不是frequency/Re/Im阻抗谱；还没有做正弦解调或GITT本征扩散辨识。其graphite/SiOx三电极体系也不能直接当成纯回收石墨/Li半电池。

### 4. 独立组 split-conformal 残差校准

CSV列 `record_id,group_id,batch_id,protocol_id,role,predicted,observed`；role为training/calibration/test。预测与实测单位一致。条件组不能重复、跨角色重叠或混合批次/协议。不能把同一电芯的许多相关时间点改成不同group_id来增加样本数。

冻结且独立训练的预测器，以独立校准绝对残差建立阶次：

k = ceil((n_cal+1)(1−alpha))；q = 第k小残差；区间 = 预测 ± q。

阶次超过校准数量时，返回无界区间、不计算有意义的留出覆盖率。95%有限区间至少19个独立校准观测，还需独立训练/测试组。训练独立性、同分布与冻结由明确声明支持，不能由文件结构认证；主动选点和漂移可能破坏交换性。

这是轻量适配，**不是完整SC-CP**的增广等距回归、oracle条件覆盖算法。现代作者仓库的网格/插值、默认标签范围也不能未经核验直接搬入。

## 建立了基准，但未作为完整算法接入

- BOED：线性高斯EIG解析基准，验证零信息、更大噪声、相关观测等；没有宣称变分BOED复现或真实测试协议自动推荐。
- BASQ：审阅了重要性权重被均匀化覆盖的源码路径；未把该路径迁入。完整实现还需正确矩保存、标准化似然、proper先验、证据/多峰基准和隔离依赖。
- LogEI：学习了对数稳定化与平滑的区别；未把“对EI取log”冒充qLogNEHVI。完整官方引擎需Torch/GPyTorch/BoTorch。
- BE-CBO：制备不可行、仪器故障、导入异常、求解失败、成功但性能低必须分开。旧网络及随机回退不直接搬入，须先有真实失败标签。
- iMFBO：输入相关可靠性和成本模型需要同域配对数据。源码beta调度与论文公式、旧依赖和本机路径需核查。A/B不同材料不当成同一函数的保真度。

## 验证与运行

57项相关测试通过；实际打包API跑通EIS导入、公开频域求解、NEHVI、有限/无界校准，以及真实MJ1 Parquet读取。解析RC传递函数与时域积分作单位/符号/频域基准；这些软件检查不替代真实材料验证。

双击根目录启动入口，新版数据在 `data/workbench_scalar6`，首次复制旧scalar5并保留旧库。模板仍是关键数据表，没有新增必须填写的复核/日期列。数据录入、EIS CSV结构检查、残差校准使用内置运行时；EIS模型、NEHVI和Parquet需本机项目与WSL环境。
