# 测量动作选择：方法定义、等价关系与证据边界

日期：2026-10-15。范围仅为既有13候选、单目标、5种数学场景的合成验证。不接入平台、真实材料、多目标、LCA或经济模块。

## 核心问题

在相同信息、动作权限和总预算上限下，按最终候选效用选择测量，是否比按候选间差异的方差缩减选择测量，得到更小的终端简单遗憾？另用模型×选点规则对照分析收益来源。

原有1400场是5场景×40个独立真值/噪声实例×7个配对方法，不是1400个独立问题。实例1000—1039及烟测0—1均为开发用途；新验证使用20000起的互不重叠实例。五种场景是固定数学条件，不是五个独立材料领域。

## 状态与观测

有限目标集合X包含13点；六维参数θ的联合正态先验在各消融中仅改变指定方差。观测动作a满足yₐ=bₐ+hₐᵀθ+εₐ，εₐ为已知方差独立高斯噪声。动作可测参考响应、目标响应、参数坐标、替代协议或重复；费用在选点前已知。目标f(x)=bₓ+hₓᵀθ，学习器只接收已揭示观测。模型外正弦真值不属于该推断模型，用于检验失配边界。

坐标r、d是无量纲数学类比；没有将D50直接等同有效颗粒半径，也没有声称是真实扩散动力学模型。三次确认是同制备的独立噪声读数，不是三次独立再生。

## 与标准KG的关系

给定数据D，终端决策是x*(D)=argmaxₓ μ_D(x)，损失为maxₓf(x)−f(x*(D))。假设固定候选集合、可积目标、正确的内部贝叶斯条件化和该终端规则，后验期望简单遗憾为

R(D)=E[maxₓ f(x)|D]−maxₓ μ_D(x)。

观测动作a的期望风险下降为

R(D)−E_{yₐ|D}[R(D∪{a,yₐ})]
=E_{yₐ|D}[maxₓ μ_{D∪{a,yₐ}}(x)]−maxₓ μ_D(x)。

证明只需对第一项使用条件期望塔式法则使其相消。右侧就是标准一步知识梯度，θ不可辨识并不会自动产生新的采集函数。该等价性是模型内部贝叶斯风险关系，不是对模型外真值或真实材料的无条件保证。

本实现再除以确定费用c(a)，得到信息价值/费用的贪心规则。它不等于完整有限预算动态规划最优策略，也不继承任意多步最优性。

## 线性高斯情形的可独立计算形式

若θ|D~N(m,C)，vₐ=hₐᵀChₐ+σₐ²，则新观测引起的目标后验均值可写为μ'_x=μ_x+sₓZ，其中s=FChₐ/√vₐ，Z~N(0,1)。因此KG=E[maxₓ(μₓ+sₓZ)]−maxₓμₓ。

新实现排序直线斜率、建立上包络，在各活跃区间按正态密度解析积分。它是已有有限相关正态KG的计算方式，非原创算法。独立核查枚举全部直线交点并积分；再用SciPy自适应积分抽查。31/63/127点Gauss-Hermite仅用于开发集数值敏感性比较。

## 必要对照

- 两种核心选点规则：KG/费用与目标对比方差缩减/费用。后者使用G=F−行均值，单次观测使tr(GCGᵀ)减少||GChₐ||²/vₐ，是明确的A最优设计准则，不是另造算法名。
- 三种观测模型：完整联合模型；把r方差压至1e−12的固定坐标消融；把协议差异方差压至1e−12的无差异消融。2×3构成6个必要组合，足以分离主效应与交互。
- 完整模型的plug-in EI/费用作为第7个传统参考，明确其不是qNEI或噪声BO最强通用方法。主要比较不依赖击败该弱化参考。

所有方法共享完整初始数据、候选、观测映射、先验信息（指定消融除外）、动作权限、价格、预算、终端规则和停止阈值。直接EI允许相同动作，但自身不赋予间接观测正的EI，不能据此称它实现了部分观测KG。
