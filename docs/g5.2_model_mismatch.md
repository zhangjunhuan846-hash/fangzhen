# Gate 5.2 — 模型失配（model-form error）污染辨识参数

> **结论：在结构错误的模型下，优化器会用错误的 $D_s$ 补偿缺失物理 —— 而且
> 在低倍率下这件事是"看不见"的。**
>
> 三个可复现的发现：
> ① 失配把 $D_s^*$ 拉偏 **最多 −27.7 %**，而低倍率下残差仍只有 **1.66 mV**（看起来很成功）；
> ② 残差地板随倍率**单调增长 56×**（1.66 → 92.57 mV），高倍率下缺失物理**无法再被吸收**；
> ③ **在错误模型下，真值不是最优解** —— 低倍率辨识出的"错"参数，跨 protocol
> 比真值好 **3.4×**；而 1.5C 的"看似恢复真值"其实是**参数失去杠杆作用的假象**。
>
> 运行命令：`python scripts/identification/g5_2_model_mismatch.py`（约 270 s）
> 报告 JSON：`outputs/fitting/g5.2/g5_2_report.json`（gitignored）

## 1. 设计

| | 生成模型 | 反演模型 |
|---|---|---|
| **Control** | SPM | SPM |
| **Mismatch** | **SPMe** | **SPM** |

每个臂跑遍数据集**实际拥有**的全部倍率，**始终只辨识一个参数**。

> **倍率可用性（必须记录）**：门控要求 C/20、C/10、C/5、0.5C、1C、2C，
> 但 **chen2020 只有 0.1C(C10)、0.5C(C2)、1C、1.5C(1p5C)**。
> 矩阵建在**实际存在的倍率**上，缺的三种在报告里标明。

```text
cell          02
D_s_true      2.0e-15 m2/s（两个臂相同）
初值          3 个（1e-15, 4e-15, 1e-14）
optimiser     pybop.SciPyMinimize(method="Nelder-Mead", maxiter=400)
数据           无噪声（这一关要把失配与噪声分开）
```

## 2. Control：链路没坏（Gate 1 PASS）

| 倍率 | $D_s^*$ | 相对偏差 |
|---|---|---|
| C10 (0.1C) | 1.999979e-15 | −0.001 % |
| C2 (0.5C) | 1.999979e-15 | −0.001 % |
| 1C | 1.999979e-15 | −0.001 % |
| 1p5C (1.5C) | 1.999979e-15 | −0.001 % |

**跨倍率散布 0.00001 dex**，最差 $|$偏差$|$ **0.00379 %**。
→ 同模型下 $D_s$ 是一个**与 protocol 无关的常数**，符合"材料参数"的预期。

---

## 3. Mismatch：参数被污染（Gate 2）

| 倍率 | $D_s^*$ | 相对偏差 | $\Delta\log_{10}D_s$ | **残差地板** | 真值处 RMS |
|---|---|---|---|---|---|
| C10 (0.1C) | 1.499796e-15 | **−25.01 %** | −0.1250 | **1.6562 mV** | 5.6571 mV |
| C2 (0.5C) | 1.446921e-15 | **−27.65 %** | −0.1406 | **7.0108 mV** | 26.4222 mV |
| 1C | 1.679975e-15 | **−16.00 %** | −0.0757 | **33.0200 mV** | 56.8561 mV |
| 1p5C (1.5C) | 1.992946e-15 | **−0.35 %** | −0.0016 | **92.5719 mV** | 93.8336 mV |

**跨倍率散布 0.13905 dex**（control 是 0.00001）。
多初值散布全程 ≤ 0.00007 dex —— **不是优化器不稳，是答案本身在漂。**

### ③ 两个现象的方向**相反**，这很关键

```text
倍率上升 →  参数偏差 Δlog10 缩小   (−0.125 → −0.140 → −0.076 → −0.002)
倍率上升 →  残差地板 单调放大      (1.66  → 7.01   → 33.02 → 92.57 mV，56×)
```

**低倍率**：失配几乎被 $D_s$ 全部吸收 —— 参数错 25 %，但残差只有 1.66 mV。
**高倍率**：吸收失败 —— 参数回到真值附近，残差却高达 92.6 mV。

读法：**"高倍率下识别出了真值"不是成功，是危险信号。**
那时 $D_s$ 已经失去对残差的杠杆作用，优化器停在真值附近只是因为**那里不是最小值也差不多**，
而不是因为模型对了。

## 4. 最危险的发现：**错误模型下真值不是最优解**（Gate 4）

用某一倍率辨识出的 $D_s^*$，**不重新拟合**直接预测其他倍率（RMS，mV）：

```text
 from\to       C10        C2        1C      1p5C
       C10     1.656     7.683  unreach  unreach
        C2     1.833     7.011  unreach  unreach
        1C     2.845    14.365    33.020  unreach
      1p5C     5.602    26.186    56.419    92.572
    (true)     5.657    26.422    56.856    93.834
```

把每一行与最后一行（**真值在同样 protocol 上的残差**）比：

| 用什么 $D_s$ | 在 C10 上 | 在 C2 上 | 在 1C 上 |
|---|---|---|---|
| $D_s^*$(C10) | **1.656**（真值 5.657）→ **好 3.4×** | **7.683**（真值 26.422）→ **好 3.4×** | unreachable |
| $D_s^*$(C2) | **1.833** → 好 3.1× | **7.011** → 好 3.8× | unreachable |
| $D_s^*$(1C) | **2.845** → 好 2.0× | 14.365 → 好 1.8× | **33.020** → 好 1.7× |
| $D_s^*$(1p5C) | 5.602 → 1.01× | 26.186 → 1.01× | 56.419 → 1.008× |

> **在错误模型下，被辨识出的"错"参数系统性地优于真值** ——
> 在跨 protocol 预测上也一样。

**这就是最危险的场景**：如果你手上只有 SPM 的拟合结果，
你会报告 $D_s \approx 1.45\times10^{-15}$，它**在每一个 protocol 上都比真值拟合得好**，
残差看起来健康，跨倍率也"可迁移"。**没有任何残差信号会提示你它是错的。**

### 而"可迁移性"检验在这里失效了（反向）

直觉上"跨 protocol 失败"是失配的警报。但这里：
- **低倍率 → 高倍率**：**完全跑不通**（5 个单元格 unreachable）
  —— $D_s^*=1.50\times10^{-15}$ 让 SPM 在 1C/1.5C 上提前到达截止，仿真窗覆盖 < 50 %。
- **高倍率 → 低倍率**：跑得通但很差（5.602 vs 1.656）。

→ **不存在 protocol 无关的 $D_s$。** 低倍率拟合出的那个"有效 $D_s$"
不只是不准，它在高倍率下**结构上就不兼容**。

## 5. 四条判据

| Gate | 判据 | 结果 |
|---|---|---|
| 1 | Control：SPM→SPM 恢复真值 | **PASS**（最差 0.00379 %） |
| 2 | Mismatch：记录偏移与地板，**不要求恢复真值** | **PASS（已记录）** |
| 3 | 倍率一致性：报告 $D_s^*$(rate) 是否恒定 | **PASS（已报告，0.13905 dex，非恒定、非单调）** |
| 4 | Cross-protocol transfer（不重拟合 + oracle 对照） | **PASS（已报告，5 个单元格不可达）** |

判据刻意**不是**"恢复真值 X % 以内" —— 失配条件下真值本就不该是答案，
那样会把一个真实的科学结果判成失败。

---

## 6. 边界（必须一起引用）

- **仍是合成数据**。真值在两侧都是已知的；这一关换掉的是**模型形式**，
  不是数据来源。真实实验还有别的不确定度。
- 只测了**一个方向的失配**（SPMe → SPM）。
  反方向（SPM → SPMe）以及 DFN ↔ SPMe 未测。
- **只测了一颗电芯（cell 02）**、一个参数集（Chen2020）。
- 倍率覆盖不全：门控要的 C/20、C/5、2C **不在这个数据集里**。
- `unreachable` 用的是**覆盖率门（< 50 % 判失败）**。
  这是刻意的设计（宁可失败也不在残片上调参），但它把一部分
  "参数没意义"的情况表达成了"跑不完"，读的时候要知道这层编码。
- **没有**结论说"SPM 不能用"。结论是：
  **在 SPM 下辨识出的 $D_s$ 是 effective parameter，不是材料常数**，
  而且它"看起来很好"这件事本身就是失配的证据。

## 7. 这一关回答了什么（接上主线）

$$\boxed{\text{parameter fit} \;\neqq\; \text{parameter identification} \;\neqq\; \text{physical transferability}}$$

- G5.0/5.1 证明了"**拟合得出来**"（同一模型、加噪声）
- G5.2 证明了"**拟合得好不等于参数对**"：
  错误结构 + 错误参数可以给出比真值更好的曲线，而且低倍率下**无残差信号**

## 8. 下一步

- **G5.3 双参数 $\{D_s, R_p\}$**：经 $\tau_d\sim R_p^2/D_s$ 强耦合。
  预期：单条曲线只能定**扩散时间尺度**，不能分别唯一确定两者
  → 二维 cost 面出现**狭长谷**。这也直接关系到 G5.2 的偏移能不能被"另一个参数"吸收掉。
- **反向失配**（SPM 生成 → SPMe 反演）与 **DFN** 作为上界，
  用来判断偏移的方向性。
- **G5.4 真实数据 + cross-protocol**：真正的检验。
  G5.2 已经给出了它该长什么样的先验：**低倍率区是"看不见的陷阱区"**。
