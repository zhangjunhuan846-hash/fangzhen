# Gate 5.1 — 加噪声 synthetic recovery（$D_s$）

> **结论：$D_s$ 在 0.5 – 5 mV 噪声下仍可辨识；主导不确定度来自"噪声实现"
> 而不是优化器。**
>
> **但有一处必须写明的限度**：只有 3 个种子，**"是否存在系统性偏差"未被确定**
> （见第 4 节）。表里的"偏差"读数小于种子间散度，不能当系统性偏差用。
>
> 运行命令：`python scripts/identification/g5_1_noise_recovery.py`（约 410 s）
> 报告 JSON：`outputs/fitting/g5.1/g5_1_report.json`（gitignored）

## 1. 为什么要做这一关

G5.0 是 **inverse crime**：生成数据与反演数据用同一模型、同一物理结构、同一参数定义。
它只能证明**实现没坏**。

这一关给观测加噪声，开始问真正的科学问题：

> **数据不再精确可复现时，$D_s$ 还可辨识吗？**

**噪声只加在观测上，正向模型完全不动。** 所以任何偏离都归因于
"噪声" + "观测量对该参数的约束强度"，而不是模型变了。

```text
dataset/cell/rate   chen2020 / 02 / C2      model  SPM
D_s_true            2.0e-15                 z = log10(D_s)
噪声水平            0 / 0.5 / 1 / 2 / 5 mV（高斯）
种子                0, 1, 2（每个种子一次独立抽样）
初值                3 个（1e-15, 4e-15, 1e-14）
每格恢复次数        3 seeds × 3 inits = 9（含 0 mV 共 45 次）
```

## 3. 三个结论

### ① `fit RMS` 紧贴注入噪声 —— **优化器没有拟合噪声**

| 注入 σ | 拟合残差 RMS | 比值 |
|---|---|---|
| 0 mV | 0.003 mV | — |
| 0.5 mV | 0.492 mV | 0.98 |
| 1 mV | 0.983 mV | 0.98 |
| 2 mV | 1.966 mV | 0.98 |
| 5 mV | 4.915 mV | 0.98 |

这是**质控信号，不是结论**，但很关键：

- 若残差 **远低于** σ → 优化器在拟合噪声（过拟合），恢复值不可信
- 若残差 **远高于** σ → 模型够不着数据（结构不足或其他误差源）
- 实测比值 **0.98 稳定在 5 个噪声水平上** → 两者都不是

### ② 主导不确定度是**噪声实现**，不是优化器

- **多初值散布**：全程 ≤ 0.00007 dex（5 mV 时 0.00005）—— 完全稳定
- **种子间 std**：随 σ 增长，5 mV 时 ±0.00146 dex

→ 换个初值几乎不影响结果；**换一次噪声抽样影响大得多**。
这意味着：**报恢复精度时应当报"对噪声实现的敏感度"，而不是"优化器的收敛精度"。**

### ③ 偏差随噪声近似线性增长，但**绝对值很小**

−0.004 % → −0.33 %，跨 10 倍噪声水平约 100 倍偏差。
即在 5 mV（相对 C2 放电曲线是相当大的噪声）下，$D_s$ 仍恢复到 **0.33 % 以内**。

**这与 $D_s$ 对观测量有强作用一致**：此前实测 $D_s$ 加倍会让 RMSE 改变约 25 mV，
所以几 mV 的噪声相对信号是很小的扰动。

## 4. 限度：**"系统性偏差"未被确定**（必须一起引用）

表里"偏差"一列在 σ ≥ 0.5 时**全为负**，看着像系统性下偏。**但不能这样读**：

| σ (mV) | 平均偏差 | 种子间 std | 判断 |
|---|---|---|---|
| 2 | −0.00056 | ±0.00058 | 偏差 **小于**散度 |
| 5 | −0.00142 | ±0.00146 | 偏差 **小于**散度 |

逐种子的偏差方向也不一致：5 mV 时 seed 0 是 **+0.00025**（正），seed 1/2 是负。

→ **3 个种子不足以把"偏差"和"抽样散度"分开。**
要下"是否存在系统性下偏"的结论，需要更多种子（10–20 个量级）。

**目前只能说**：偏差的**量级**不超过种子散度的量级，即 ≤ 0.15 %（2σ 意义上，5 mV）。

## 5. 其他边界

- 噪声是**高斯、加性、独立同分布**的。真实测量误差未必如此
  （可能有漂移、自相关、与电压相关的缩放误差）。
- **仍未涉及模型失配** —— 生成与反演还是同一个 SPM、同一套物理。这是 G5.2。
- 仍是**单倍率（C2）、单参数**。
- 观测仍来自平台的合成输出，不是实验数据。

## 6. 下一步
