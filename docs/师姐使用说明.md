# 电池仿真平台 · 自助数据导入使用说明

> 你不需要写 Python 或 YAML。准备一个文件夹、按表填几个格子，双击两次就能跑 baseline。

---

## 前置准备

- 平台已经装好的电脑（含 WSL 与 pybamm 仿真环境）。
- 一个 Excel（`.xlsx` / `.xls`）或 CSV 格式的电池循环数据。
- 数据列最少要有三列：**时间、电流、电压**（其它列可选）。

---

## 第一步：复制模板文件夹

把 `user_dataset_template\` 整个目录复制一份，改成你自己的项目名（例如 `我的电池测试-2026Q3\`）。

文件夹长这样：

```
我的电池测试-2026Q3\
├── raw\                       ← 你放原始数据的地方
├── dataset_info.xlsx          ← 你填这份 Excel
├── 导入并检查数据.bat          ← 第一步要双击的
└── 运行仿真.bat                ← 第二步要双击的
```

---

## 第二步：放原始数据

把你的 CSV/XLSX 文件放进 `raw\` 子文件夹。

- 支持格式：`.csv`、`.xls`、`.xlsx`。
- 第一行必须是列名（表头），下面一行一行是测量数据。
- 文件名只允许英文/数字/下划线，避免空格和中文。

如果你有多个测试文件，全部放进去——但一次只导入一份（见第三步里的 `source_file`）。

---

## 第三步：填写 `dataset_info.xlsx`

用 Excel 打开 `dataset_info.xlsx`，里面有两个 sheet：

### Sheet 1：`experiment`（实验元信息）

本表共 **16 个字段**（下拉可选项会限制你只能选合法的值）：

| 字段 | 怎么填 |
|---|---|
| `dataset_name` | 你这个项目的英文短名（最终结果文件夹名） |
| `sample_id` | 样品编号（最终输出文件里也会出现） |
| `chemistry` | 下拉选：`LFP` / `NMC` / `LCO` / `NCA` / `Graphite` / `Other` |
| `cell_configuration` | 下拉选：`full_cell`（成品电池）或 `half_cell`（对锂半电池） |
| `working_electrode` | 下拉选：`positive` / `negative` |
| `counter_electrode` | 自由文本，如 `lithium_metal` / `graphite` |
| `nominal_capacity` | 标称容量，单位 Ah（例如 0.003112） |
| `active_material_loading` | 面容量 mAh/cm²（半电池必填，整电池可不填） |
| `electrode_area` | 电极面积 cm²（半电池必填） |
| `electrolyte` | 自由文本 |
| `voltage_lower` | 电压窗口下限（V） |
| `voltage_upper` | 电压窗口上限（V） |
| `temperature` | 实验温度（°C） |
| `protocol` | 自由文本，如 `CC_Cover5` / `DST_50SOC` |
| `current_sign` | 下拉选：**`discharge_positive`** 或 **`discharge_negative`**。**务必跟你的原始数据一致**，否则会校验失败 |
| `initial_soc` | 可不填（半电池会从静置电压反推） |

### Sheet 2：`column_mapping`（列映射）

把 Excel 里能下拉选 `source_file`（覆盖 `raw\` 里的某个文件名）后，**逐行** 告诉你这份原始文件的每一列叫什么、什么单位：

| canonical_field | source_column | source_unit |
|---|---|---|
| time | 原始列名（如 `Time [s]`） | `s` / `ms` / `min` |
| current | 原始列名（如 `Current [mA]`） | `A` / `mA` / `uA` |
| voltage | 原始列名（如 `Voltage [V]`） | `V` |
| capacity | （可选）原始容量列 | `Ah` / `mAh` |
| cycle | （可选）循环编号列 | — |
| step | （可选）工步编号列 | — |
| temperature | （可选）温度列 | `K` / `C`（会自动转换） |

**最低必填三行**：`time`、`current`、`voltage`。

平台不会替你猜你的列名和单位——表里写什么就用什么。如果你写错单位（例如把 mA 写成 A），电流会差 1000 倍，最终仿真会全错。

---

## 第四步：双击"导入并检查数据.bat"

在文件夹里**双击** `导入并检查数据.bat`。

会发生的事：

1. 弹出黑色窗口（CMD），里面打印进度。
2. 完成后会在文件夹里生成 `outputs\你的dataset_name\validation_report.html`。
3. 黑色窗口**会自动暂停**——按一下任意键关闭它。

如果窗口里出现 **红色 FAIL**（不暂停、直接退出），说明校验失败：

- 不要慌——双击打开 `outputs\你的dataset_name\validation_report.html`。
- 这是一个网页报告，浏览器里能看到 13 项检查里哪些失败、为什么失败。
- 旁边还有一个 `issues.csv`（机器可读的问题清单）。

按报告里写的原因回到第三步改正 `dataset_info.xlsx`，**重新双击 BAT** 即可。

---

## 第五步：检查报告

用浏览器打开 `outputs\你的dataset_name\validation_report.html`：

- 顶部写 **DATA IMPORT = PASS** 表示可以继续仿真；
- 如果写 **SIMULATION = NOT AVAILABLE**，说明当前没有合适的参数集（这条数据跑不了 baseline）。这不一定是数据错——可能是材料参数集还没收录你的材料。**这种情况下请停止，不要尝试改 BAT 跳过**。

报告里还有：

- 一张电压-容量预览图（`voltage_capacity_preview.png`），肉眼检查电压走向是否合理；
- 参数匹配说明（`dataset_manifest.json`）：会显示本次用了哪个参数集，**是不是从你的数据拟合出来的（默认 `fitted_to_dataset = false`）**。

---

## 第六步：双击"运行仿真.bat"

回到文件夹，**双击** `运行仿真.bat`。

会发生的事：

1. 弹出黑色窗口跑仿真（第一次会慢一些，后面会快）。
2. 完成后会生成 `outputs\你的dataset_name\baseline_metrics.csv`：
   - `rmse_time_aligned_mV`：电压误差 RMS（毫伏），越小越接近实验；
   - `bias_time_aligned_mV`：平均偏置（毫伏），正值表示模型电压整体偏高；
   - `coverage_fraction`：时间对齐覆盖率（小于 1 表示有部分仿真时段没匹配上实验）；
   - 其它列是电流、温度、容量、仿真耗时等元信息。
3. 黑色窗口**会自动暂停**——按一下任意键关闭它。

**重要：这些数字只能叫 zero-fit baseline**，意思是"用一套现成材料参数、不做任何拟合、直接跑"。它不代表模型验证，也不代表你的材料参数已经"对"——只是告诉你"用现有参数能解释你这条数据的百分之多少"。更详细的解读在 Phase A2 残差报告里，不在这里展开。

---

## 出错怎么办

| 现象 | 大概率原因 |
|---|---|
| 双击 BAT 后窗口一闪而过 | 看 `outputs\你的dataset_name\validation_report.html` 或 `issues.csv` |
| 报告里 FAIL = `CURRENT_SIGN_CONFLICT` | 第三步 `current_sign` 选反了，回到 Excel 改成 `discharge_positive` 或 `discharge_negative` |
| FAIL = `VOLTAGE_RANGE` / `TIME_MONOTONIC` | 数据本身有问题（例如电压在窗口外、时间回退），需要回去找原始数据 |
| 报告里 PASS 但 `SIMULATION = NOT AVAILABLE` | 这种化学/构型当前没有可用参数集。**不要自己改 BAT**——请联系维护者 |
| 仿真阶段超时（黑色窗口卡住很久） | 第一次跑数据较大时常见，可以等；如果超过 30 分钟仍无输出，请联系维护者 |

---

## 不允许改的东西

- ❌ 不要编辑 BAT 里的命令；
- ❌ 不要编辑任何 `.py` / `.yaml` 文件；
- ❌ 不要把 `raw\` 里的原始文件移到别处或改名后再跑；
- ❌ 不要试图在 Excel 里手动编辑 `outputs\` 下的文件——这些是自动生成的，下次跑会被覆盖。

只允许改：`raw\` 里的数据文件 + `dataset_info.xlsx`。
