# 回收石墨科研工作台 V0.1（2026-10-12）

交付入口位于 `outputs/rg_workstation_20261012_01a12de8/`：工作簿、双击校验入口和使用说明。

本版用于实验前建档、受控公式正反算与数据归档。用户已有原料/工艺/表征，尚无半电池数据，因此输入模板没有实测值或预测值。

工作簿有 11 页：开始、设计计算、原料、样品工艺、表征、极片、电芯、测试、性能记录、目标约束、推荐记录。数据表单行单记录、固定第 6 行标题、预留 200 行；录入区与计算区分开，关联编号用下拉和校验器核对。

后端 `python -m user_tools.rg_workstation check --workbook <path> --out <archive_dir>` 仅使用标准库。读取 XLSX 原始标量，重新计算衍生值；输入字段里的公式拒绝执行。归档包括源表、哈希、CSV、JSON、HTML，每次保留独立版本。

10 个受控设计变量通过 4 条乘除关系传播：活性质量、参考容量、倍率电流、涂层体密度。仅求解单未知关系；多未知返回 partial，冲突返回 conflict。约束先核验单位，重叠边界取交集，固定值矛盾不覆盖原输入。百分数与零/缺测分别处理。

当前参考容量不是自主电化学容量预测；当前工艺/性能目标只记录，不反解真实再生条件。物理模型用途与工艺优化用途分别保存，未来优化器仍须实施 final_confirmation 的读取隔离。

验证：12 个独立数值/边界/记录关系测试；工作簿输入变更触发公式重算、跨表活性质量关联、零/空白边界及冲突示例；全表错误扫描与逐页预览；导出后只读检查下拉、表、冻结窗格和未填输入。

尚未在原生 Microsoft Excel 中交互运行；原生结构可读取，计算使用 Artifact Tool 验证。PyBaMM、PyBOP、真实参数辨识及 GP/BO 不属于本版已实现能力。

构建器放在交付目录 `_build/build.mjs`，使用 Codex bundled artifact-tool 与 schema 生成，修改输入契约后应重新构建并验证。
