# 第二轮：量化误差与窗口聚合（运行前协议）

首轮和三份公开CSV均视为开发证据，不修改旧结果或旧诊断器。v2独立实现，只生成诊断建议，不写回原始数据，不接入平台自动修复。

输入仍限定A、Ah和已知充/放容量列。必须显式提供精度预算：电流绝对误差、容量绝对误差、原始时间误差、电流相对误差及来源。文件显示位数只能形成“显示量化假设”，不等于仪器校准精度；默认假设也不能当已验证真值。预算缺失时不接受完整方案。

对原始完全相同的相邻记录允许在分析副本去重，保存原行索引。公开适配器以完整原始行（含电压等字段）的签名判断，不能只比较t/i/q。真正时间非递增仍阻断整份应用。

同一步骤内、同符号且相邻电流变化不超过5%的区间连续分组。非重叠积分窗口至少16区间，容量净变化达到端点误差和的8倍时闭合，最长2048区间；末尾至少4区间仍保存。重置或缺值打断窗口。不能跨步骤、回跳或缺失值拼接。

令q=ΔQc−ΔQd，则容量误差界为eQ=2eQc+2eQd；积分P=Σ(Ij+Ij+1)Δtj/7200，误差界由电流绝对+相对误差和时间端点误差逐区间求和，按候选时间乘数变换。选择极性s后，检查[sP−eP,sP+eP]和[q−eQ,q+eQ]是否相交。eQ由测量端点误差相加，不随窗口样本数缩小；不把同源误差当独立噪声除以√n。误差界不包含任意未采样电流变化，限于稳定电流段。

容量证据：至少3个信号超过2eQ且误差区间不跨零的窗口支持时才可独立辨识。任一信号充分的窗口与候选明显冲突即否决；零电量/粗量化不视作冲突。稳定电流下充放计数器同时有效增长、步骤内容量异常下降均阻断应用。无法证实容量一致性时明确输出precision_limited，不伪称双证据通过。

时间戳仍使用中位误差≤2%、90分位≤25%、至少10区间。方向状态只用于约定“充电为正”，不从电压趋势推断，不是PyBaMM极性。若时钟唯一且明确方向状态唯一、容量证据无明确冲突，可接受尺度/符号标准化建议，但容量核验可能仅为precision_limited；原始数据仍不修改。真实回跳、非有限输入或候选非唯一始终拒绝。

验证：开发种子31；冻结规则后使用2000–2099。保留首轮10场景，另加低电流粗量化、粗量化+毫秒反符号重置、粗量化下错误容量尺度、粗量化且无时钟/状态（证据不足）、只改电压的重复时间、明确完全重复、容量证据不足但时钟与状态明确。每场景100独立轨迹，同一场景内种子独立，跨场景共享种子按配对不合并独立样本。比较v1/v2，区分数值错误接受与违反拒绝策略；每场景报告比例、Wilson区间、配对接受率差。预设目标：可辨识场景≥95%正确建议，危险场景无违规接受；低信息场景允许保守拒绝，不能为通过而放宽预算。

公开CSV仅作开发回归，Landt精度假设据固定四位小数设置电流/容量绝对预算各1e-4，时间预算1e-3原单位；其他长浮点导出不据位数推断物理精度，另列1%电流相对误差为待核实假设。若通过只能说明这些假设下相容。v2结果不证明专利新颖性或真实材料收益。
