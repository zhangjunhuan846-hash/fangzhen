# EIS 与 MPC 有限诊断记录

## 数据范围与结果统计

CALB 60129 的 EIS、HPPC 和驾驶是回顾性对照：EIS 测试发生在驾驶之后，状态匹配也不能完全确认。报告中 27 条记录为 3 个方法 ×（6 个驾驶窗口 + 3 个 C/3 脉冲窗口）；驾驶均值仅使用前 18 条。下表为逐驾驶窗口联合辨识减 HPPC-only 的 RMSE，单位 mV；窗口属于同一电芯，不构成六次独立电芯实验。

| 工况 | 窗口 1 | 窗口 2 |
|---|---:|---:|
| UDDS：开环 / EKF 预测步 | −0.214 / +0.127 | −0.108 / +0.179 |
| US06：开环 / EKF 预测步 | −0.121 / +0.120 | −0.233 / +0.062 |
| WLTP：开环 / EKF 预测步 | −0.529 / +0.115 | −0.193 / +0.110 |

每个开环窗口略低、每个预测步略高；不据此声称统计显著性。误差为每窗口的 RMSE，不是整个测试加权合并后的 RMSE。SOC 参考是代理值。固定的是 HPPC 数据量，联合方案还需额外测量 EIS。

## EIS 时间尺度与优化路径

原拟合的输入列是处理后 MAT 的 `Frequency`、`Zreal`、`Zimg`；代码按 `Zreal + j Zimg` 和 Hz 读取，模型使用 `2πfτ`，阻抗以 Ω 计算。四条限频谱各 24 点，范围 0.5208–998.264 Hz；各谱都有 1 个正虚部点。单 RC 的虚部不能表示正虚部，其可能体现感抗等现象，但仅凭这一步不能确认机理。这里检查的是处理后 MAT 列与模型公式的方向、单位，不等同于与仪器原始软件逐点核对。

| 标称 EIS SOC | EIS 初值 τ（s） | EIS 初值是否触下界 | HPPC 最终 τ（s） | HPPC 对应转折频率（Hz） | 剖面扫描最小 τ（s） |
|---|---:|---|---:|---:|---:|
| 80% | 0.250 | 是 | 23.84 | 0.00667 | 0.00173 |
| 60% | 0.250 | 是 | 24.46 | 0.00651 | 0.00153 |
| 40% | 0.250 | 是 | 25.66 | 0.00620 | 0.00163 |
| 20% | 0.250 | 是 | 24.65 | 0.00646 | 0.00219 |

拟合使用原始 HPPC 约 0.10 s 的全记录中位间隔，但先按累计电量重采样到 1 s；各节点取约 10 s、约 58 A 的放电脉冲及后续静置，拟合窗口合计 120 s。HPPC 转折频率远低于所保留 EIS 频段，因而这个频段不能完整覆盖对应转折。

在 10⁻⁵–600 s 的对数网格上固定 τ，按原方法的 `|Z|` 权重最小化 R0、R1 的残差；电阻边界仍与原方法一致。四条谱均出现 0.0015–0.0022 s 附近的内部最小值，而原优化的 τ 下界是 0.25 s。剖面接近下界时仍向更短 τ 降低，说明原始结果受下界限制，并表明同一个 1RC 支路在现有频域和时域数据中对应的时间尺度差别很大。该扫描放宽了诊断范围，**没有改变正式模型或质量门槛**；频域最小点不能直接解释为物理时间常数或置信区间。频段、状态不匹配和 1RC 无电感等结构限制均可能影响结果，不能唯一归因。

实际优化器重跑捕获了各次请求与实际初值、结果、目标值、调用次数、停止消息和回退标志；重跑参数与已保存模型一致到数值容差。以 80% 节点为例，HPPC 三组初值 τ 为 10、1、100 s，EIS 初始化给出的请求 τ 为 0.25、0.125、0.5 s，其中 0.125 s 被裁剪到 0.25 s 附近。两组仍有不同的实际初值，均收敛到约 23.84 s，目标函数平方和约 0.49609；前者调用 6、11、7 次，后者 8、9、9 次。未发生回退，这几次运行没有证明 EIS 初始化节省计算。所有节点、三个起点的完整数据在 `optimizer_calls.json`。

## MPC 拖尾

诊断重复了上一轮的预设失配：被控模型 R0/R1 各增加 30%、容量下降 5%、换热系数下降 20%，控制器与 EKF 保持名义参数。步长 20 s，6 步预测视界为 120 s，起点 SOC 0.55，目标 0.60；外部评价器使用被控模型 SOC 判停。额外记录的是控制器决策前状态和第一步预测，不代表完整预测视界的最小约束余量。

| 项目 | 原 EKF 反馈 | 理想被控模型 SOC 反馈 |
|---|---:|---:|
| 达到评价目标 | 2460 s（123 步） | 380 s（19 步） |
| 首次电流低于 2.25 A 的输出时刻 | 160 s | 320 s |
| 对应动作前的模型 / 控制器 SOC | 0.57038 / 0.59343 | 0.59367 / 0.59367 |
| 求解器回退次数 | 0 | 0 |

原方案在第一个明显降流时求解器成功，命令与施加电流均为 2.100 A；动作后的实际电压距 4.2 V 上限约 0.371 V，温度距 45 °C 上限约 19.51 °C。控制器的名义第一步末端预测约 3.828 V，距其电压保护界仍有余量。没有记录完整视界最紧约束，不能仅凭第一步排除所有未来约束作用。原始追踪在动作、电压、模型 SOC 和 EKF SOC 上与前一轮 123 步结果完全一致。

理想诊断只将真实模型 SOC 注入控制器，极化估计仍使用 EKF，其他失配不变。显著缩短的到达时间和原始降流时约 +2.3 百分点的估计偏差，支持优先检查估计与模型失配；不能证明哪个物理参数单独造成偏差。当前目标为 SOC 跟踪、温度项及控制变化惩罚，严格的模型 SOC 达标判停也会影响尾部表现。不能把理想 SOC 运行作为实际 BMS 效果。结果是单个随机种子的合成实验，不是硬件或实测热安全结论。
