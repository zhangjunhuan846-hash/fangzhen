# 现在可做的合成动作决策验证

日期：2026-10-14。目的：把“参数联合不确定性→不同测量动作→预算→最终推荐”落实为可运行的数学原型，检查机制与失败边界。不是新算法或材料收益证明。

采用已有的一步知识梯度KG：预测一次观测后目标候选最大后验均值的期望增量，除以该动作预先声明的费用。后验期望简单遗憾的期望减少等于KG，因为真值最大值项在条件期望下相消。联合参数模型和目标/参考协议差异项支持补表征、另一协议、目标测试及重复。没有提出新的采集函数。

这一步与此前C3计划的区别：C3的科学物理诊断决策仍未完成；本原型仅实现线性高斯观测下的动作选择，不读取实际G5/G6报告，不调用PyBaMM，不进行实物控制，不自动修改生产工作站推荐。

## 运行前冻结

- 5种场景：无耦合；耦合但排序稳；耦合改变目标协议排序；目标/参考协议三次差异；模型不能表示的正弦差异。
- 40个独立真值/噪声实例/场景，实例1000—1039；不是同一材料池追加随机初始化。总1400场策略运行。
- 7策略：所有动作随机；按费用D最优信息设计；直接目标EI；EI/费用；联合模型KG/费用；固定粒径坐标消融；无协议差异消融。所有策略有相同动作权限、共同初始数据和预算。
- 总预算10相对单位，初始参考协议测量和最终模拟确认均收费，提前预留确认费1.6。费用非人民币、能耗或LCA。
- 13个有限候选，已知高斯噪声、6维联合参数。坐标r、d只是无量纲类比；参考协议观测包含d−2r，目标协议可额外依赖r。不是把D50等同有效R，也不代表真实扩散公式完整模型。
- 目标是无量纲合成效用，不是1C容量、ICE或再生收率。真值由独立抽取参数/额外正弦函数产生，不以学习器预测反馈。匹配场景仍是同一线性函数族的理想数值控制。
- 选择动作前落盘可用动作、已观测数据哈希和后验；揭示模拟观测后再更新。最终确认新增独立噪声、仅作评测，不反馈训练；只是同制备重复读数，不能代表独立再生制备。
- 每策略最终都推荐最大目标后验均值候选，统一计算真实简单遗憾、精确最优命中、与最优差距≤0.5比例、区间诊断及各类动作费用。不能靠全部拒绝降低误判。
- 数值积分使用31点Gauss-Hermite；验证后仅检查固定规则，不因获胜与否再调参数。保存代码快照、协议、逐场和逐动作证据。

数值边界修复：首轮输出保留在`outputs/analysis/action_validation_20261014`。在仅剩无收益动作可付费时，约1e−16舍入误差会让KG仍购买无关表征，导致无耦合/排序稳场景平均浪费0.035单位。加入适用于全部非随机策略的≤1e−12采集值停止规则并扩展边界测试；修复后的结果输出到新目录`action_validation_20261014_v2`。这不是根据获胜结果修改场景、参数、费用或主指标。

取证链修复：独立审阅确认v2全部1400场及6383条动作记录计算一致，但指出最终候选没有独立预先落盘。v3新增`final_decisions.jsonl`，在真值和确认读出前保存候选、后验预测、数据哈希与预留费用，并扩展测试。只增加记录，不改变算法/费用/真值/指标。v1、v2均保留；这些在同实例上的修复属于开发数值控制，不称独立确认性验证。

## 对结果的约束

分场景配对bootstrap区间为探索性、未做多重比较修正。不能把低遗憾自动解释成减少实际达标费用。EI是后验均值门槛的plug-in版本，非qNEI；D最优是总参数信息基线。本轮没有强ARD GP、完整HVKG、多目标、真实费用和材料前瞻验证，不能代替此前B1/B3。

无耦合/排序稳时，联合KG应避免没有排序价值的补表征。模型外正弦情形应允许出现性能/区间失败，不声称自动识别任意模型错误。若匹配场景有收益，也只能支持机制概念；论文创新仍需区别已有KG与多保真/部分观测BO。

依据：[多保真BO，Song等，AISTATS2019](https://proceedings.mlr.press/v89/song19b.html)、[HVKG，Daulton等，ICML2023](https://proceedings.mlr.press/v202/daulton23a.html)。此处只借鉴成本/信息动作思路，没有复现这两篇完整算法。
