## 2. 五个实测结果

**① 接口通了，而且溯源是**真**的。** `run_metadata.json` 里 D_s 那一条是

```json
{"__callable__": "graphite_Ds_three_region_+0.500dex", "__module__": "identification.representations", "__qualname__": "shape_override.<locals>.shaped"}
```

外加 `parameter_override_sources` 里的 `shape / amplitude_dex / phi_mean / phi_rms / region_edges`。
函数型参数曾经让**整次运行**失败（`_json_safe` 之前），现在它是可复核的记录。

**② 跨阶段逐位复现（本次最有分量的核对）。** 三个形状里 `constant` 就是
$\phi_0=1$，即 G6.1c 那次扫描。它由**另一条构造代码**（`representations.shape_override`
而不是 `replay_scan.build_multiplier_override`）产生，却给出同一组数：

| 窗口 | 本次（constant） | G6.1c | |
|---|---|---|---|
| `GITT-charge#t475` | **0.0988** dex | **0.0988** dex | 逐位 |
| `GITT-discharge#t120` | **0.8966** dex | **0.89663** dex | 逐位 |

⇒ 新表示层与已发布的那条路**等价**，估计器只有一份。

**③ 哪个形状"看得见"是窗口的函数**（不是判据，但是本轮最实质的观察）：

| 窗口 | linear vs constant | three_region vs constant |
|---|---|---|
| `GITT-charge#t475` | **63.48 mV**（可见） | **0.90 mV**（< 1 mV，**不可分辨**） |
| `GITT-discharge#t120` | **0.54 mV**（< 1 mV，**不可分辨**） | **2.86 mV**（可见） |

同一个幅度（RMS 归一化 +0.5 dex），换一个窗口，"哪个形状重要"就反过来。
这与 G6.1c 的"**方向本身是变量**"同族，但这次是从**形状**侧独立测出来的：
**"用更复杂的形状"不是普遍更优，它是（状态 × 形状）的函数。**

**④ 不可达探针点会把带宽**量窄**——`N2` 不是形式主义。**

| 窗口 | 形状 | 不可达幅度点 | 1 mV 带 |
|---|---|---|---|
| t475 | constant | 2 / 41 | 0.0988 dex |
| t475 | linear | **10 / 41** | **0.0359 dex** ← 不可当测量值 |
| t475 | three_region | 0 / 41 | 0.1371 dex |
| t120 | 三个都 0 | 0 / 41 | 0.8966 / 1.9594（截断）/ 0.6333 |

`cost` 对不可达点返回 `inf`，`band_width` 会**丢弃**这些点，剩下的点被当成相邻点
⇒ 带被量窄。所以凡 `n_unreachable_amps > 0` 的行，带宽只能当**上限**。
报告 JSON 用 `bands_measured_with_unreachable_amps` 把这些行单独列了出来。

**⑤ t120 上出现 `bounded`**：`linear` 的带 1.9594 dex 且**右侧截断** ⇒ 判定落在
`bounded`（可报下界，不许报点估计），措辞与 G6.1b-1/G6.1c 一致。这是报告生成器第一次
在真实产物上走到 `bounded` 分支 —— 那条"one-sided sensitivity region"的规范句子被自动带上了。

## 3. 四条接口事实（都是实测，写代码前不知道）

1. **pybamm 把函数型参数的实参以符号传入**，不是浮点数：第一次跑就炸在
   `np.asarray(x, dtype=float)` 上，实参长这样 `Maximum(0.0, Minimum(1.0, ...))`。
   ⇒ 形状函数必须**符号与数值两条路都支持**，否则"接口通了"是假话。
2. **`pybamm.Heaviside` 在 26.8 不存在**；只有 `EqualHeaviside` / `NotEqualHeaviside`，
   而且约定与直觉相反：实测 `EqualHeaviside(left, right)` 在 `left <= right` 时返回 1。
   三段形状因此写成 `1 - NotEqualHeaviside(x, a)`，并配一条"符号侧与数值侧在同一 x
   必须给出同一个 φ"的测试。
3. **标量输入必须返回 Python `float`，不能返回 0 维 ndarray**：
   `pybamm_symbol * np.array(0.5)` 会变成 `Array` 子节点，随后在域合并时崩
   （`'numpy.ndarray' object has no attribute 'domains'`）。测试抓到的。
4. **参考 D_s 本身是 pybamm 符号**（含 `exp(…/R)`）：`ref(0.5, 298.15)` 返回
   `Multiplication`，所以 `assert f(...) == pytest.approx(...)` 比较的是两个**符号对象**，
   返回真值对象 ⇒ **断言恒成立**。本轮的测试一律改成 `.evaluate()` 取数或
   monkeypatch 一个真正的浮点参考；`tests/test_recovery_stats.py` 早先已经这么做了。

## 4. 表示的定义（RMS 归一化是可比性的前提）

$$\log_{10} D_s(x) = \log_{10} D_{\rm ref}(x) + \text{amp}\cdot\phi(x)$$
$$\phi_0 = 1,\qquad \phi_1 = \sqrt3(2x-1),\qquad \phi_2 = \tfrac{1}{\sqrt2}(1,-2,1)$$

三个形状 **rms = 1**，除 $\phi_0$ 外 **mean = 0**（数值复核容差 2e-3，因为 $\phi_2$ 有两个
跳变，均匀网格的求积误差就是 ~5e-4 —— 那是测量误差不是形状误差）。不做归一化的话，
"linear 比 constant 弱"可以只是因为系数小；`phi_2` 带非零均值就会与 `phi_0` 混在一起。

**$\phi_2$ 只用了一个方向**（两端 vs 中段），不是三个自由系数：G6.1c 已实测
"加自由系数只加带宽、不加信息"。本门要回答的是接口问题，一个方向足够。

## 5. 边界（引用时必须一起引用）

- **只验接口**：不做辨识、不做优化、不拟合任何测量。这里出现的带宽是"接口通了之后
  顺带看到的数"，**不构成任何 $D_s(x)$ 形状的辨识结论**。
- 带宽是 **model-to-model** 量：同模型、同尺度、无噪声、无模型形式差异 ⇒ 理想条件最好情况。
- 数据集是公开 benchmark（`dlr_gitt`，DLR Hydra.0b），**不是任何回收石墨样品**；
  `dataset_role: benchmark` ⇒ 不构成验证。
- 1 mV 水平、0.30 dex 上限、±1 dex 扫描、0.05 dex 网格：全部是**声明**值，与 G6.1b-1/G6.1c 同口径。
- 只测了两个窗口、单电芯、26 °C、SPM。"哪个形状可见"的结论**只在这两个窗口上成立**。

## 6. 决策

- **不进 3-region / smooth basis**。本轮与 G6.1c 给出的是同一个方向上的两个独立证据：
  瓶颈在激励，不在参数化。
- 回收石墨 case 需要的是 **$D_s$、$k_0$、$R_{ct}$、Q 这些标量**（导师判断），
  而标量路径（`GITT-charge#t475`，B = 0.0988 dex）已经是**可辨识**的。
  ⇒ 下一步是 **Phase 1/2：接真实样品数据**，不是继续扩展函数表示。
- 若将来真要用形状，本门留下的是**可复用接口**：`shape_override` + `MultiplierScan`
  的可注入 builder（代价函数只有一份，形状换了代价函数不许换，有源码级守卫测试）。
