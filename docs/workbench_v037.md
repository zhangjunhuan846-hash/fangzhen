# v0.3.7 描述符与机器学习

双击项目根目录的“启动科研工作站.bat”，打开“描述符与机器学习”。

1. 选择当前方案自动关联，或上传描述符CSV。
2. 选择用途和目标。当前数据尚无半电池结果时，可先预测真密度、BET等已测表征；未测容量不能训练。
3. 点击“读取数据与描述符”，勾选输入列。选择手动保留、训练折内相关性筛选或相关性与冗余控制。
4. 比较均值、岭回归、PLS、随机森林、Extra Trees与GP，查看分组MAE/RMSE、逐折预测图、入选频率及留出置换重要性。
5. 保存的模型可以下载预测表头，输入新样品后预测。再生工艺模型可以在有限已知候选中做单目标GP选点；修改实验数据后重新建模会更新描述符筛选。

## 数据与验证

CSV必需record_id、group_id、batch_id和指定目标列，其他列自由选择。CSV中每个输入声明“实验前已知”或“制样后测得”。group_id指独立工艺条件，不是电芯号；同条件的重复实验必须同组。第一版最多500行、30个描述符，至少5个独立工艺组；留批次验证至少两个批次。

工作站关联按样品编号连接处理工艺、表征、极片、电芯。容量/ICE记录按倍率、循环节点和温度筛选，电解液、隔膜和电压窗口必须明确且一致。重复电芯先按样品平均；极片描述符若同一样品有不同值，会保留为缺失，不随意挑一行。

已录入工艺完全相同且批次相同的样品会分到同组，未记录的工艺差异不能由软件识别。需要更精细分组或新增标量时可用自定义CSV；不用修改原模板。

填补、编码、缩放、去常数和固定数量筛选均在训练折中拟合。模型按同一交叉验证表现选择，因此胜出的模型仍需独立验证；当前报告不是最终前瞻预测证据。误差先按记录计算绝对值/平方，再按工艺组等权平均，重复数量不增加组权重；v0.3.8修正了此前带符号误差先平均造成的抵消。

相关性冗余筛选是Spearman/类别相关比的轻量适配，不是原版互信息mRMR。重要性是留出置换误差增加，不是SHAP或因果机制；每折少于3个留出样品时不展示有效重要性。

GP采用固定Matérn核与声明的相对观测噪声；标准差是潜在函数探索量，不是经校准的置信区间。单目标有限候选UCB/LCB不等于多目标NEHVI；原有两目标NEHVI入口仍保留。未知类别、缺失、外推、新批次或已测描述符组合不自动推荐。GP未胜过均值基线时暂停自动推荐。

## 运行与存储

此机已安装兼容NumPy2的scikit-learn、joblib、cloudpickle、threadpoolctl；ML由现有WSL Python运行，Windows界面不打包重型依赖。其他电脑需要同样的项目与WSL运行环境，EXE不是跨电脑零依赖安装包。

模型与输入快照、原始CSV、逐折预测、重要性、预测结果存于data/workbench_scalar8/jobs。首次启动备份复制scalar7（或更旧数据库），不会覆盖旧版数据。只加载平台自己生成的模型文件，不接受上传pickle/joblib。已有LCA、经济分析和仿真入口保留。

本版完成通用用户数据建模入口，尚未完整集成TabPFN/xRFM、原版FABO、SHAP显著性算法、SISSO、谱特征自动提取或多保真优化。论文与完整源码已归档，后续接入依据在outputs/descriptor_paper_study_20261013/论文源码与接入评估.html。

软件测试与合成数据流程通过不表示已验证真实回收石墨性能，更不改变现有Chen留出失败及BO不胜随机的结果。
