# 石墨负极第一阶段测试方案 v2（Phase 0 → Phase 1 → 回收石墨）

状态：**草案 v2，待填实验室 GITT 既有协议数值**
定位：先**减少变量**，把「参数识别」与「设计优化」彻底分开。
科学问题（主线）：**回收碳材料的性能恢复程度如何转化为模型参数变化，并进一步指导电极结构重新设计。**

## 变更记录（v1 → v2）

| 项 | v1 | v2 | 原因 |
|---|---|---|---|
| 阶段划分 | 一次性做完 OCP/GITT/EIS/倍率 | Phase 0 最小闭环 → Phase 1 参数集 | 第一轮同时做材料+模型+优化，证据都不够强 |
| 载量 | 两档都做 GITT | **低载量识别 + 高载量验证** | 低载量更接近单颗粒扩散假设；高载量检验模型迁移能力 |
| EIS SOC 点 | 5 个 | **3 个（10/50/90%）** | 够判断 R_ct 变化趋势 |
| GITT 协议 | 固定 C/10×10min+60min | 用实验室既有协议 + **量化约束**（见 §3.3） | 石墨平台区与斜坡区响应不同 |
| 数据角色 | 未区分 | **辨识集 / 验证集在数据层强制分离** | 避免"你只是拟合"的质疑 |
| 措辞 | 表观参数 | 明确 **apparent / effective** 用词表 | 模型依赖的有效扩散系数 ≠ 材料常数 |

## 1. Phase 0：最小闭环（只做 G0）

目标：**证明"数据格式 → PyBaMM → 实验曲线 → 误差评价"这条路能跑通**，不是拿到完整参数集。

| 项 | 设定 |
|---|---|
| 体系 | Graphite‖Li，CR2032 |
| 温度 | 25 ± 1 ℃（全程记录实际温度） |
| 材料 | **仅 G0（商业石墨）** |
| 平行样 | **3 颗** |
| 载量 | 单档，**1.5–2.0 mg/cm²**（识别用） |
| 极片 | 固定配方、固定压实；记录实际厚度/孔隙率 |
| 电压窗口 | 0.005–1.5 V；**锂化（充电）侧电流 ≤ C/10**（防析锂污染 D_s/R_ct） |
| Li 对电极 | 新鲜刮制，厚度 ≥ 2× 需求（过量，避免 Li 成为限制因素） |

测试序列（**顺序不可换**）：

| # | 测试 | 参数 | 产出 | 数据角色 |
|---|---|---|---|---|
| 1 | 化成 | C/20 × 2 圈 | 初始容量、ICE | 建档 |
| 2 | 准平衡曲线 | C/20 充 + C/20 放，**双支分别保存** | lithiation / delithiation 分支 | 辨识集 |
| 3 | GITT | 实验室既有协议（见 §3.3 约束） | `Time/Current/Voltage` 原始序列 | 辨识集 |
| 4 | EIS | **10 / 50 / 90% SOC**，10 kHz–10 mHz | R_Ω、R_ct（趋势） | 辨识集（可选参数） |
| 5 | 倍率验证 | 放电 C/10、C/2、1C、2C；充电固定 C/10 | 实验曲线（**不参与拟合**） | **验证集** |

> 化成必须在参数测试之前；GITT 与 EIS 之间不要插倍率测试（避免不可逆结构变化污染）。

## 2. Phase 1：建立 `commercial_graphite_v1` 参数集

### 2.1 参数与来源

| 参数 | 来源 | 必需/可选 |
|---|---|---|
| OCP（充/放双支） | 准平衡曲线 | **必需** |
| `D_s(SOC)` | GITT（PyBOP） | **必需** |
| 电极结构：thickness / loading / porosity | 直接测量 | **必需** |
| 粒径 / 形貌 | SEM | **必需** |
| `k0`（表观交换电流密度） | EIS | 可选（若不做需显式声明） |

### 2.2 低载量识别 → 高载量验证

```
低载量 1.5–2.0 mg/cm²  →  识别材料参数（更接近单颗粒扩散假设）
                                  ↓
高载量 3.5–4.0 mg/cm²  →  验证模型能否预测厚电极行为
```

高载量实验**只用辨识出的参数做前向预测**，不回头调参。这一条是整条路线的可信度所在。

### 2.3 数据角色分离（平台层强制）

| 角色 | 内容 | 规则 |
|---|---|---|
| `identification` | OCP 双支、GITT、EIS | 可参与参数辨识 |
| `validation` | 倍率曲线、高载量曲线 | **任何阶段不得进入拟合目标函数** |

平台侧落地：`dataset_role` 写入导入清单，拟合阶段增加一道门——若发现
validation 标记的数据出现在拟合输入中，直接报错退出。

### 2.4 验收门（仅判数据可用性，不设 RMSE 竞赛）

| Gate | 判据 |
|---|---|
| G1 平行样 | 3 颗 C/10 容量离散 ≤ 5% |
| G2 化成稳定 | 第 2 圈库仑效率 ≥ 99% |
| G3 OCP 双支完整 | 两支均覆盖目标 SOC，无跳点 |
| G4 GITT 可用 | 每脉冲静置末端 dV/dt < 1 mV/h；拟合 R² ≥ 0.98（记录最差值） |
| G5 EIS 可拟合 | 半圆与扩散尾可分离 |
| G6 验证不加参 | 高载量前向预测与实验同量级，且**未回改参数** |

## 3. 三条量化约束（协议无关，必须满足）

### 3.1 载量下限

识别用极片不要低于 ~1 mg/cm²：过薄会放大边缘效应与电流分布不均，
测得的 `D_s` 失去代表性。**1.5–2.0 mg/cm² 是合理区间。**

### 3.2 材料对比的电极一致性

G0 / 回收石墨对比时，固定配方与目标载量，但**不要强求压实密度完全相同**
（回收石墨粒径/振实密度不同，强行同压会引入裂纹等伪差异）。

正确做法：**记录每片实际厚度与孔隙率，作为显式协变量报告**；
比较结论必须能区分"材料差异"与"电极结构差异"。若两者混在一起，只能写
"在当前电极工艺下观测到的综合差异"。

### 3.3 GITT 协议约束

不机械固定脉冲时长，但必须满足：

1. 单脉冲 ΔSOC 足够小（建议 ≤ 5%），保证半无限扩散近似成立；
2. 静置足够长——判据 **末端 dV/dt < 1 mV/h**（实用上 30–60 min）；
3. 脉冲电流使 IR 降落在小量级，且锂化方向电流 ≤ C/10；
4. 石墨平台区与斜坡区**都要覆盖**（平台区响应快、斜坡区慢，取样点要密一些）。

→ 具体脉冲/静置数值：**待填实验室既有协议**（若实验室有标准 GITT 协议，优先沿用，
保证与组内其他数据可比）。

## 4. 回收石墨怎么接（Phase 2）

商业石墨 baseline
→ 回收石墨 `RG_raw` / `RG_500` / `RG_800`
→ **不重测全部**，重点看参数变化：

| 参数 | 反映什么 |
|---|---|
| OCP | 结构变化（层间距、缺陷） |
| `D_s` | 固相扩散 |
| `k0` | 界面动力学 |
| porosity / thickness | 电极工程（回收料更难压实） |

模型回答的问题：**回收石墨需要什么样的电极设计？**

配套表征（与电化学并行、不阻塞）：Raman I_D/I_G、XRD d002、SEM 粒径、
ICP（Cu/Al/Fe）、XPS（表面官能团，可选）。

## 5. 措辞守则

| 不要写 | 要写 |
|---|---|
| 真实 D_s | **apparent / effective solid-state diffusivity**（模型依赖的有效值） |
| 杂质导致 D_s 下降 | 表观 D_s 下降，同期 ICP/Raman 显示…（**禁因果直连**） |
| 我的石墨参数集 | 基于本实验数据辨识的**表观参数集**（参考参数集另称） |
| 拟合得很好 | zero-fit baseline + 定向辨识分阶段报告，validation 数据不参与拟合 |

## 6. 第一批实验清单（最终版）

**烧**：G0 / G500 / G800（三档热处理）

**表征**（三个全做，便宜且不占电池位）：Raman、XRD、SEM

**电池**：先只做 **G0**，3 颗，测：
1. C/20 化成 ×2
2. C/20 双向平衡曲线（双支保存）
3. GITT（实验室协议）
4. EIS ×3 SOC（10/50/90%）
5. 倍率验证（C/10、C/2、1C、2C，不参与拟合）

模型跑通并出 `commercial_graphite_v1` 后，再扩展 G500/G800，最后接回收石墨。
