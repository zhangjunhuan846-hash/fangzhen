> **结论：$\beta = \dfrac{d\log D_s^*}{d\log R_p} = 2.075$（控制臂）/ $2.056$（失配臂），
> 两个臂都紧贴理论参照 $\beta=2$。**
>
> **实操含义**：粒径的相对误差会**以平方**放大到扩散系数：

> | $R_p$ 误差 | $D_s$ 偏差（实测，控制臂） | $\beta{=}2$ 预测 |

## 1. 定位

这是 Chen2020 方法学分支的**收尾**，不是新的科学问题。它**刻意不做**两件事：

- **不去解释** Chen2020 的 5.22 µm 对应你手上 PSD 的什么（那需要 G5.5 主体，且缺测量元信息）
- **不虚构**"数量/面积/体积加权"三套 PSD —— 没有对应原始测量时，那是制造伪信息

它只做一件窄而可辩护的事：**把 $R_p$ 按已知倍数扰动，测由此产生的 $D_s$ 偏差。**

```text
R_p = R_p,0 × (1 + δ),   δ = −20 %, −10 %, −5 %, 0, +5 %, +10 %, +20 %
每个固定 R_p 重新辨识 D_s（R_p 以常数覆盖方式真正钉住）
β = d log(D_s*) / d log(R_p)
```

**协议**：0.1C 单协议 · 单参数（$D_s$）· 无噪声
**两个臂**：control（SPM 生成→SPM 反演）· mismatch（SPMe 生成→SPM 反演）

---

## 2. $\beta=2$ 是**参照线**，不是答案

若观测量只约束扩散时间尺度

$$\tau_d=\frac{R_p^2}{D_s}$$

则固定 $\tau_d$ 要求 $D_s \propto R_p^2$，即 **$\beta = 2$ 精确成立**。
仿真**不会**严格等于 2 —— G5.3 已证明 $R_p$ 还通过**比表面积**（$a=3\epsilon/R$）
与通量边界条件进入模型。所以 2 画作参照线，**偏离它本身就是结果**。

## 3. 结果

### 3.1 $\beta$

| 臂 | 过原点拟合 | LOO 范围 | **绕 δ=0 拟合** | **LOO 范围** |
|---|---|---|---|---|
| control | 2.0751 | [2.071, 2.081] | **2.0751** | **[2.0708, 2.0812]** |
| mismatch | 2.1984 | [1.224, 2.958] ✗ | **2.0564** | **[2.0533, 2.0606]** |

> **判据修正（本轮踩的坑）**：失配臂在 $\delta=0$ 处**本身就带 −25.0 % 的偏差**。
> 过原点的幂律拟合把"失配偏移"折进了指数里 → LOO 范围炸到 `[1.22, 2.96]`。
> **绕 $\delta=0$ 归一化**（每个 $D_s^*$ 除以它在 $\delta=0$ 的值）把常数偏移除掉，
> 剩下的才是 $R_p$ 灵敏度 —— LOO 立刻收紧到 `[2.053, 2.061]`。
> **控制臂两种算法给出同一个数**（偏移为零，归一化不起作用），这本身是一致性检查。

**两个臂都得到 $\beta \approx 2.06\text{–}2.08$，与理论参照 $2$ 只差 $+0.06\sim+0.08$。**
→ **$R_p$ 的平方律在这份模型上近似精确成立。**

### 3.2 偏离参照线的部分有结构，不是噪声

控制臂实测偏差**减去** $\beta{=}2$ 预测：

| δ | 实测 | $\beta{=}2$ 预测 | 超出 |
|---|---|---|---|
| −20 % | −36.96 % | −36.00 % | **−0.96 %** |
| −10 % | −19.62 % | −19.00 % | −0.62 % |
| −5 % | −10.10 % | −9.75 % | −0.35 % |
| +5 % | +10.67 % | +10.25 % | +0.42 % |
| +10 % | +21.93 % | +21.00 % | +0.93 % |
| +20 % | +46.24 % | +44.00 % | **+2.24 %** |

**超出量随 $|\delta|$ 单调增长**（0.35 % → 2.24 %），符号随 $\delta$ 翻转。
→ 这是**温和的非线性**，与"$R_p$ 除 $\tau_d$ 外还有第二条进入路径"一致，
**不是**拟合噪声。**但量级很小（≤ 2.3 %），实用上平方律足够。**

## 4. 产出：**粒径表征精度要求**

由 $\beta \approx 2$ 直接反推：

$$\frac{\Delta D_s}{D_s}\;\approx\;2\,\frac{\Delta R_p}{R_p}$$

| 若粒径表征精度为 | 则 $D_s$ 的不可约偏差约 | 用途 |
|---|---|---|
| ±2 % | ∓4 % | 足以支撑定量材料学结论 |
| **±5 %** | **∓10 %** | **`D_s` 可辨识到 10 % 量级** |
| ±10 % | ∓20 % | 只能做半定量 |
| ±20 % | ∓37~46 % | 不可用于"材料参数"表述 |

**这条曲线可以直接用来定实验方案**：先声明 $D_s$ 的目标精度，再反推粒径表征需要做到什么程度。

---

## 5. 边界（必须一起引用）

- **仍是合成数据**，且**协议只有 0.1C 一个**。$\beta$ 是否依赖倍率、协议集、模型
  **未测** —— 由于 $\beta$ 反映的是几何映射而非动力学，预计变化不大，但**这是推测**。
- $R_p$ 的扰动是**均匀的相对扰动**，不是真实测量误差的分布形态
  （真实误差可能有偏、与粒径相关、非高斯）。
- **本节没有解决**"Chen2020 的 5.22 µm 到底对应哪一个测量统计量" ——
  那需要 G5.5 主体，且**卡在缺 PSD 元信息**（仪器 / 加权方式 / 颗粒定义）。
- 本关**只做方法学收尾**，完成后 **Chen2020 分支封存**，主线转回 graphite。
