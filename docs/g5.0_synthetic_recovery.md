# Gate 5.0 — 单参数 synthetic recovery / **集成验证**

> **结论：PASS（作为集成验证）。**
>
> ## 这个 gate 的名字很重要 —— 它是**集成验证**，不是"参数辨识完成"
>
> 平台现在能从一个**已知真值**生成的电压响应里把该参数找回来。
> 这证明的是**管道连通**：
>
> `PyBOP → parameter override → PyBaMM → cost → optimizer → recovered parameter`
>
> **但它不是"真实实验里的 $D_s$ 能被可靠识别"的证据。**
>
> ## 必须写明的边界（inverse crime）
>
> $$\text{synthetic recovery success} \;\neqq\; \text{experimental identifiability}$$
>
> 因为**生成数据与反演数据用的是同一模型、同一物理结构、同一参数定义**。
> 这是典型的 **inverse-crime** 场景：它适合证明**实现没坏**，
> **不适合**用来证明真实 $D_s$ 可辨识。
>
> 具体地，这一关**没有**证明：
> - $D_s$ 在**真实**数据上可辨识（→ G5.4）
> - $D_s$ 与其它参数**不互相补偿**（→ G5.3 二维）
> - 测量噪声下仍可辨识（→ G5.1）
> - 模型结构不对时不会用错误的 $D_s$ 去补偿缺失物理（→ G5.2）
>
> 真值处 cost **精确为 0** 也是构造出来的，不是拟合出来的 ——
> 因为那份"观测"就是平台自己在真值处的输出。
>
> 运行命令：
> `python scripts/identification/g5_0_synthetic_recovery.py`
> 报告 JSON：`outputs/fitting/g5.0/g5_0_report.json`（gitignored）
>
> **保留价值**：这一关产出的是**方法基础设施证据**（见第 3 节），
> 是后续 identifiability 研究的零号门槛，不是"调参实验"。

## 4. 这一关发现并修掉的两个**判据错误**（值得记）

两次失败都不是物理问题，而是**我把验收标准写错了**。记下来是因为它们很容易重犯。

### 错误 A：容差比网格间距还小

初版 `argmin 距真值 ≤ 0.15 dex`，但粗扫 7 点的**间距是 0.4 dex**。
**一个网格对最低点的定位精度不可能优于它自己的步长** —— 这条判据实际测的是网格分辨率，不是物理。
真值恰好落在两个网格点之间，于是"失败"。

**修法**：容差取 `max(名义容差, 实测分辨率)`；并加一层**细化扫描**（围绕粗扫 argmin），
让最终结论报在实际达到的分辨率上（0.043 dex）。

### 错误 B：用线性插值去估"真值处的 cost"

为防粗网格骗人，我加了第二条：**真值必须不差于网格最低点**。
但我用 `np.interp` 插值，得到 2.9e-04，把真值判成了"更差"。

原因是**这个最低点极窄**（约 $10^{-3}$ dex 宽），线性插值在这里暴涨 4 个数量级 ——
那是**插值器的性质，不是成本曲面的性质**，不该让判据失败。

**修法**：**直接把真值加进去实测**，不插值。实测值 0.000e+00。

> 教训：*在一个尖峰型最低点附近，插值不能替代测量。*
> 同理，"优化器停在这里"不能替代"这里是最小值" —— 所以扫描不能省。

## 5. 一处必须说明的设计选择：成本定义在**重叠时间窗**上

$D_s$ 越大，到达截止电压越晚；越小则越早。所以**候选的仿真窗长度依赖于候选本身**，
而观测网格是固定的。

处理方式：每次评估只在 $t \le \min(t_{\rm obs,end}, t_{\rm sim,end})$ 上打分，
并在审计里记录**覆盖比例**。覆盖 < 50 % 的候选直接判失败（$J=\infty$）。

这就是粗扫里 **4 个点 unreachable** 的来源：$D_s \le 7.9\times10^{-16}$ 时仿真提前结束，
覆盖不足。**宁可判失败，也不在一个残片上调参** ——
只拿一小段比较会让一个错得很远的参数看起来很好。

## 7. 后续主线：从"找得到"转向"可信吗"

判据要从

> "优化器能不能找到真值？"

改成

> **"这个参数在噪声、模型失配、不同 protocol 下，是否仍具有唯一性与可迁移性？"**

| Gate | 内容 | 回答的问题 |
|---|---|---|
| **G5.1** | 加噪声 synthetic recovery（0.5 / 1 / 2 / 5 mV） | 测量噪声下还能不能辨识？恢复偏差、方差、多初值稳定性 |
| **G5.2** | 模型失配（SPMe 生成 → SPM 反演） | 结构不对时，优化器会不会用错误的 $D_s$ 补偿缺失物理 |
| **G5.3** | 双参数 $\{D_s, R_p\}$ | 二者经 $\tau_d \sim R_p^2/D_s$ 强耦合 —— 单条曲线是否只能定**扩散时间尺度**，而不能分别唯一确定两者 |
| **G5.4** | 真实实验 + cross-protocol 验证 | 在一类实验上辨识、**在另一类上证明**（GITT/低倍率辨识 → 0.5C/1C/2C 预测） |

**不要**继续"再找一个参数 → synthetic truth → optimizer 找回来"。
那类实验的科研增量会迅速下降。
