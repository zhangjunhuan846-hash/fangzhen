# 回收石墨半电池：模型参数与数据表头核查

本清单核对了PyBaMM官方参数化文档、Chen2020参数化研究及本项目已安装模型的直接参数符号。区分三类对象：材料表征/工艺描述符，物理模型直接参数，以及以曲线/函数形式提供的数据。材料描述符不自动等于模型参数。

## 1. 文献与当前模型证据

- [Chen等2020，电池模型实验参数化](https://doi.org/10.1149/1945-7111/ab9050)：包含几何、孔隙/活性体积分数、OCP、动力学及电解液输运等不同来源的参数，不能只靠一条电压曲线任意补齐全部量。该研究是全电池参数化，不能直接作为再生石墨验证。
- [PyBaMM官方参数化示例](https://docs.pybamm.org/en/v25.12.0/source/examples/notebooks/parameterization/parameterization.html)：参数有标量、函数和求解时输入之分，要求取决于模型方程及选项；扩散率示例明确允许浓度函数。
- [天然石墨电极孔隙率计算示例，RSC原文及补充信息](https://pubs.rsc.org/en/content/articlehtml/2020/ee/d0ee02230f)：用于说明电极密度、组分比例及各固相真密度的体积换算。该文章含硅与锂沉积策略，本项目不借此采用其材料性能或工艺方案。
- [石墨孔结构研究的密度测量](https://pmc.ncbi.nlm.nih.gov/articles/PMC10650451/)：区分体密度、表观密度与氦气测得的真密度。粉体/块体测量的体积定义应记录，不能将不同密度互换。
- 本机PyBaMM 26.8下，等温单活性相、positive工作槽位的半电池SPM/SPMe/DFN分别暴露29/34/35个直接参数符号，导出见 `outputs/rg_workstation_scalar/model_parameters_local.json`。这是该具体配置的符号清单，函数闭包、几何与额外热/老化选项仍需核查，不是所有电池通用固定数量。

## 2. 第一优先级：应该测量并记录的标量

|对象|参数|作用/来源|
|---|---|---|
|石墨粉体|真密度ρ，g/cm³|粉体固相体积换算；测法和体积定义写备注，不默认采用理想石墨密度|
|石墨粉体|D10、D50、D90，μm|粒度及其分布；有效扩散尺度不能自动等于D50/2|
|石墨粉体|模型有效颗粒半径及依据|球形模型的几何假设/独立尺度，片状取向和聚集体需说明|
|极片|面积、干涂层质量、涂层厚度、铜箔厚度|活性质量、载量与电极几何；涂层厚度不含铜箔|
|极片|石墨/导电剂/粘结剂干质量分数|质量口径、容量归一化、固相体積换算；三者合计及未记录添加物需要核对|
|极片|导电剂、粘结剂有效真密度|复合电极孔隙率不能只用石墨真密度；复合粘结剂可使用明确定义的混合有效密度|
|极片|孔隙率、干涂层密度、电导率|电解液和电子输运；粉体电导率不等于极片电导率|
|半电池/测试|实际电流、倍率参考容量、温度、电位上下限|规定输入、倍率定义和终止条件；电位相对Li/Li⁺|
|隔膜/电解液/锂片|隔膜厚度/孔隙率、配方/盐浓度/注液量、锂片厚度|半电池其余组成与实验可追溯性；注液量常不直接进入标准饱和一维模型，但可影响实验一致性|

碳含量、灰分、ICP、BET、拉曼ID/IG、XRD d002/Lc/La等继续保留在材料表征表。这些主要用于纯度、结构、工艺效果和代理模型解释；标准SPM没有从这些量自动计算Ds的确定关系。

再生粉体的称重比例并不自动等于100%活性石墨比例；碳含量也不等于可逆活性石墨含量，应在质量归一口径中说明。

## 3. 第二优先级：应校准、采用公开来源或以函数提供的模型输入

|参数|形式|建议获得方式|
|---|---|---|
|OCP U(x)|曲线，V vs Li/Li⁺|低倍率/静置测试与明确的锂化度坐标；不能用一个电压标量替代|
|固相扩散率 Ds(x,T)|函数或声明范围内常数近似|GITT、倍率/脉冲辨识与可辨识性检查；不是直接从ID/IG推算|
|交换电流密度 i0(c_s,c_e,T)|函数或限定状态常数|EIS/动力学实验或独立辨识；i0的单位与反应速率常数k的单位不同|
|最大固相锂浓度 c_max|标量，mol/m³|化学体系与可信参数化；不得把任意短周期实测比容量直接当完全利用的理论最大容量|
|初始锂化度 x0|状态，0–1|与同一OCP坐标一致的初始状态；x0不自动等于任意软件SOC定义|
|活性材料体积分数 ε_am|标量|由可靠质量、体积、组成派生，或独立测量；不等于石墨质量分数|
|电解液 De、κ、t+、热力学因子|随浓度/温度函数或有范围的近似|与实际电解液配方一致的来源；SPMe/DFN需特别关注|
|电极/隔膜输运闭合参数|Bruggeman指数或明确的曲折度模型|测量或公开来源，二者不是可随意互换的同一数字|
|接触电阻、锂金属动力学|标量/函数|独立测量或所采用模型的来源；两电极半电池不能把对电极极化全归于石墨|

可选“仿真输入”页为这些量和来源提供固定表头、曲线文件位置。没有证据的量留空；录入尚不等于通过可辨识性或自动传入当前公开模型任务。现有任务仍明确使用公开参数/数据；自有材料的通路需要匹配、校准和独立预测。

## 4. 真密度怎样进入模型

在干质量口径一致、各固相体积可加和、全部配方组分已记录的近似下：

\[
\rho_{solid,mix}^{-1}=\sum_i w_i/\rho_{i,true},\quad
\epsilon_{pore}=1-\rho_{coating}\sum_i w_i/\rho_{i,true},\quad
\epsilon_{am}=\rho_{coating}w_{am}/\rho_{am,true}.
\]

其中ρ_coating是干涂层体密度，不是粉体振实密度；各w是归一化的干质量分数。存在封闭孔隙、未知添加物、非活性杂质或不同测量体积定义时，应重新核查适用性，不把公式结果当独立测得的孔隙率。

这也是为什么真密度应单列，而不能用振实密度代替。对于模型，它常通过孔隙率/活性体积分数间接发挥作用，不必在每个SPM参数列表中以“真密度”名字直接出现。

## 5. 当前代码的具体缺口

`governance/geometry_channel.py`现阶段读取载量、厚度、面积和D50，只输出有效半径与涂层厚度，不输出由真密度/配方决定的活性体积分数和孔隙率。其D50/2映射是既定模型假设，本次没有把它升级成适用于所有片状回收石墨的物理事实。

Ecker2015_graphite_halfcell把实际石墨放在PyBaMM的positive槽位，锂金属放在negative槽位。因此实际石墨参数不能仅根据Positive/Negative字面名称填写。当前Chen辨识的Positive参数是NMC；两个任务的物理电极意义不同。

现有记录/仿真平台还需建立来源受控的自有材料参数组装、曲线加载和一致性检查，才可把新表的数据用于可信半电池预测。本轮完成检索、表头及参数清单，不改变已有失败验收结论。
