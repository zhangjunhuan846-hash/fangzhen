## 0. 为什么必须写死这张表

不写死的后果不是"不够规范"，而是**结论不可归因**：600 与 800 的 `D_s` 差异
到底是材料的，还是两组各自选了一套来源算出来的 —— 事后无法回答。

**判据**：任何一次正式 run 里，模型的每一个参数值都必须能在 §3 找到它的

## 1. 五类来源（互斥，逐参数必须标一个）

| 类别 | 含义 | 必须记录 |
|---|---|---|
| **A 实测（本批）** | 本实验室这批样品/电芯量出来的 | 仪器、日期、原始文件、单位 |
| **B 实测派生** | 由 A 按**固定公式**算出 | 公式 + 用了哪几个 A |
| **C 参考参数集沿用** | 来自 `Ecker2015_graphite_halfcell`（89 键） | **逐键列出**，不能写"用了那个参数集" |
| **D 允许辨识** | 本轮**唯一**放开：`D_s` 的乘子 `a0`（`log10 D_s = log10 D_ref(x) + a0`） | 辨识集、协议 id、判据编号 |
| **E 不报** | 有值也不给判定 | `not_measured` + 理由指向**通路**而非数据 |

⚠️ **C 不是"照抄别人的电芯"**。`Ecker2015_graphite_halfcell` 描述的是**别人的石墨、
别人的极片工艺**。沿用它 = 声明"该参数在两类石墨间近似不变"。这个声明要么有独立依据，
要么必须在表里标成**假设**，不能默认成立 —— 这正是"商业石墨的参数不能直接适用回收石墨"
的技术落点（见 §5 的 R3）。

⚠️ **只有 D 是拟合**。任何 run 里若出现 §3 未列为 D 的参数被调整，该 run 作废。

## 2. 本轮允许的辨识量（就一个）

| 量 | 定义 | 载体 | 判据 |
|---|---|---|---|
| `a0` | `log10 D_s(x) = log10 D_ref(x) + a0`，D_s 在本参数集里是**函数**不是常数 | `parameter_overrides` 里的 callable（必须过 `_json_safe()`） | L3 的五词判定；只有 `identifiable` 报数值，`bounded` 只报界 |

**不放开**：`k0` / `Rct`（EIS 已测但无通路，见设计文档 §10.1）、`Bruggeman`、
`porosity`、`c_max`、`Ea`、SEI 与 LAM 相关键。放开任何一个都会与 `a0` 混淆。

## 4. 三处**必须显式声明**（否则静态降级）

### 4.1 几何实测值目前没有到模型的通路（**本轮最大的真实缺口**）

**事实**（可复核）：`electrode.mass_loading_mg_cm2` / `electrode.coating_thickness_um` /
`electrode.area_cm2` / `particle.d50_um` 四个键在仓库里**只出现在
`battery_sim/datasets/material_metadata.py`**（校验与摘要打印）与夹具生成脚本里，
**没有任何代码把它们变成 `parameter_overrides`**。而 `geometry_audit()` 是从
**参数集自己**反推模型几何与容量的（`eps·A·L·c_max·F/3600`），**不读实验值**。

**后果**：回收料的 `R_p`、厚度、孔隙率与商业石墨的差别，**不会自动进入模型**。
若不做任何处理，模型默认沿用参考参数集 —— 等价于**把回收料当商业石墨算**，
而这正是导师点出的"不能保证直接适用"。

**本轮允许的两种处理**（二选一，写进 run_record，不得混用）：

1. **人工转写**：由实验者按 §3.1 算好，写进 run 的
   `--overrides`/`parameter_overrides` 字典，并在 run_record 的
   `geometry_source` 里逐键写明「值 / 来自哪个实测文件 / 计算公式」。
2. **v0.1.1 接通路**：adapter 侧读 metadata → 生成覆盖 dict。
   这属**平台改动**，按纪律走 `v0.1.1` 或实验分支，不动 `v0.1.0-platform`。

⚠️ 无论哪条，**报告必须打印本轮用的是哪个 `R`**。用 13.70 µm（参数集）还是
实测 D50/2，`D_s` 读数可以差 2.4× —— 不打印就等于把"粒径变化"读成"扩散变化"。

### 4.2 截止电压：模型用的是参数集的 `0 V`，不是实验的 `0.005 V`

**事实**（可复核）：参数集自带 `Lower voltage cut-off [V] = 0`、
`Upper = 1.5`；数据集的 `lower_voltage_cutoff_V` / `upper_voltage_cutoff_V`
只在 `battery_sim/datasets/template.py::get_metadata()` 里被**写进
`voltage_window_V` 字段**，全仓没有任何 runner 拿它做参数覆盖。

纯回放（电流剖面被实测值驱动）时影响是二阶的，但**必须声明**：审稿人问
"你的仿真是在哪里终止的"，现在的答案是"参数集的 0 V"，而不是"实验的 0.005 V"。
L4 预测 1C 时这个差别会直接落在预测区间的端点上。

**处理**：本轮以**实验协议**为准，在 run 里覆盖 `Lower/Upper voltage cut-off [V]`，
并把「采用值」与「参数集原值」并列记进 run_record。这是 `parameter_overrides`
的既有能力，不需要改代码。

### 4.3 终止原因目前只能反推

**事实**：`metrics` 给出 `coverage_fraction = min(t_exp末, t_sim末) / t_exp末`
（`battery_sim/simulation/baseline.py:337,351`）—— 仿真提前终止时它 < 1，
但**终止原因本身不被记录**。而预注册 §3.3 的 L2 表要求"termination 未记录 ⇒ L2 不过"。

**处理**：run_record 里显式记两条 —— ① 实验记录的终止条件（仪器日志 / 最后一点电压）；
② 本次回放是否早停、早停在哪一点、当时的电压。**不靠 `coverage_fraction` 单独下结论。**

## 5. 可比性规则（跨样品 / 跨料源）

| # | 规则 | 为什么 |
|---|---|---|
| **R1** | 一条 series 目录**只放同料源样品** | `validate_series` 只比 `processing` 块与电极几何，**不检查 `source` / `material_class`**。已验证：一份"商业石墨未处理 + 回收未处理 + 回收 500 °C"的三组里，`applied:true` 的只有 1 份 ⇒ `len(treatments) < 2` ⇒ 整段跳过、零输出零警告。**混料源不会被发现** |
| **R2** | 跨样品比较 `D_s` 必须用**同一个 `R` 口径**，且在表里打印用了哪个 `R` | `τ ∝ R²`；不重测粒径 = 把粒径变化读成扩散变化 |
| **R3** | **商业石墨是参照系，不是处理对照**。「处理有没有用」只能靠**回收料处理组 vs 回收料未处理组** | 料源不同 ⇒ 两个变量同时变，无法归因 |
| **R4** | **BET 不进任何粒径换算** | 2.62 m²/g 的等效直径 ≈ 1.0 µm，比 D50 17.58 µm 小 17× |
| **R5** | 每个样品**重测粒径**，不用规格书值 | 规格书 D50 是**处理前**的粉；热处理的失重与破碎会改粒径 |

## 7. 一页速查

```text
实测(A)   : 载量 / 厚度 / 面积 / D50 / p-OCV 双支 / 容量(+来源+cycle) / 终止条件
派生(B)   : eps_am = 载量 ÷ (厚度 × 真密度) ; porosity = 1 - eps_am - 导电剂 - 黏结剂
沿用(C)   : 参考参数集其余键（逐键列出，标成假设）
辨识(D)   : 只有 a0（D_s 乘子）
不报(E)   : k0 / Rct（EIS 已测但无通路）
必须声明  : 用哪个 R ；截止电压取实验值还是参数集值 ；终止原因
红线      : 一条 series 只放同料源 ；商业石墨 ≠ 回收料的处理对照 ；BET 不反推粒径
```
