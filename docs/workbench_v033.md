# 科研工作站 v0.3.3

双击项目根目录 `启动科研工作站.bat`，打开新版浏览器界面。新入口为“多目标与公差 / CpK”。

## 本次完成

- 多目标方案筛选：选择容量、ICE、保持率中的至少两个指标，按固定倍率/循环号筛选记录，按样品汇总重复电芯。支持均值下限、Pareto非支配判定、重复数和标准差。拒绝混合已知温度或重复电芯ID。所有指标当前均为最大化；不支持成本最小化或新条件MOBO。
- 公差分析：干涂层质量、面积、厚度、活性质量分数、活性真密度、其他固体等效真密度、参考比容量。支持正态、均匀、固定分布；质量与厚度可设正态相关，其余输入独立。按种子重复Monte Carlo，输出均值、标准差、2.5%/97.5%分位、无效样本比例与可选规格合格比例。
- CpK/Ppk：粘贴独立重复实测值及单侧/双侧规格。总体样本标准差计算Pp/Ppk；提供带来源的组内标准差时单列Cp/Cpk。少样本、未声明稳定性/正态性仍标为探索估计，用户声明不等于工具验证。
- 每次分析保存配置、结果、方案快照、方案版本，支持历史查看和完整JSON下载。计算不覆盖实验记录。
- JSON备份可恢复为独立方案，旧版字段通过既有迁移规则转换。

## 公差公式与范围

单位：m为mg，A为cm²，t为μm，q为mAh/g，密度为g/cm³。

ρbulk = (m / 1000) / (A × t × 10⁻⁴)

Qref = (m / 1000) × w × q

εpore = 1 − ρbulk × [w / ρactive + (1−w) / ρother]

εactive = ρbulk × w / ρactive

这是干涂层的两类固体体积可加近似；不含集流体。ρother必须由其他组分质量比例和真实密度确定，不能随意填石墨密度。参考容量不是倍率性能预测。无效抽样不偷偷裁剪；区间统计仅针对有效样本，并同时报告整体无效比例与“有效且合格”的总比例。

所有波动都应对应同一种用途：工艺波动或测量误差。不要把两者和模型误差混合成一个已证实的制程分布。

## 能力指数依据

[NIST 制程能力](https://www.itl.nist.gov/div898/handbook/pmc/section1/pmc16.htm)：稳定制程、正态假设、充分独立观测以及单侧规格的定义。

[NIST 误差传播](https://www.itl.nist.gov/div898/handbook/mpc/section5/mpc55.htm)：相关输入传播时需要考虑协方差。

本工具没有自动进行控制图或正态检验。30次只是探索性提示的内部门槛，不能视为能力认证所需样本量。没有组内标准差时不伪造CpK；目前不输出能力指数置信区间。

## 数据与版本

新版数据在 `data/workbench_scalar4`。首次启动会用SQLite备份复制 `workbench_scalar3`（不存在时回退旧目录），并复制对应任务、导入与导出文件。旧目录保留。避免同时继续编辑旧版与新版；迁移后的两个数据库不会实时同步。

录入与新增分析使用程序自带的Python标准库。Excel导出仍依赖本机Codex Node运行时；电化学任务仍依赖项目和WSL PyBaMM环境。不是搬走EXE即可在任意电脑完成所有仿真。

## 验证与未完成事项

新增测试覆盖Pareto取舍/相同点/重复聚合/缺失与温度混合、密度与容量单位、相关性传播、无效抽样、固定种子复现、单侧规格/零标准差/总体与组内区分、分析记录持久化。

隔离测试目录 `outputs/workbench_analysis_tests` 的样品是合成界面测试，不进入你的正式研究数据库。
