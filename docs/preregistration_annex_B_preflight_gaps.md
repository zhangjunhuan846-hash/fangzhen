## 2. A 类：不可补救项（6 条，当前设计文档里**全部零命中**）

> 检索方式：在 `docs/graphite_heat_treatment_test_plan.md`（363 行）里逐词查。
> 下面每条都给了「为什么不可补救」。

### A1. 前处理 —— 操作参数可以后给，**但红线必须在动手前写死**

文档里 `磁选` / `过筛` / `手套箱` / `空气焙烧` / `酸洗` / `150` **全部 0 命中**。

**已定（2026-09-19）**：具体操作参数（试剂 / 浓度 / 温度 / 时长 / 筛目 / 干燥条件）
由实验方整理成表格后提供，**不必现在写进方案**。

**但下面三件事不能等表格** —— 它们是**防止自毁**，不是记录：

| # | 必须在**动第一个样品之前**定死 | 为什么 |
|---|---|---|
| a | **前处理序列对所有样品（含参照系）一字不差地相同** | 只要一个样品的前处理不同，它就从"前处理"变成**第二个自变量**；那就必须在方案里**声明为自变量**，不能还当前处理写 |
| b | **干燥温度上限 ~150 °C**（越过即分解 SEI 有机物） | 越限**等于偷偷对未处理样做了一次热处理**，未处理基线当场作废，而**事后从数据里看不出来**。若工艺确实需要更高，必须**对所有样品统一**、记成"共同处理"，并同时改 §1 常量表里的命名 |
| c | **空气 / 氧化性气氛焙烧不与热处理温度档重叠** | 重叠 = 同一个变量名对应两个不同处理。若必然重叠，写成"若干组共用同一前处理"，**不要假装它是前处理** |

⚠️ **酸洗的定位必须说清**（`method` 的取值里本来就有"酸洗"，不是禁用项）：

- 若酸洗是**所有样品的共同前处理** ⇒ 可以，但必须写进 `processing`；
  并且参照系不能再以 **as-received / `CG-AR`** 自居 —— §1 的常量表要改名。
- 若是**回收料专属** ⇒ 参照系（商业石墨）与回收组**同时差两个变量**，
  结论必须退到「当前前处理与热处理工艺下的**综合差异**」，不能写成"处理带来的改善"。

**交付格式（很重要）**：那份表格的**列名请直接用仓库闭集的键名**，否则要改代码才能读：

```text
必填：method / temperature_C / duration_h / atmosphere
可选：ramp_rate_C_per_min / cooling / atmosphere_flow_sccm / crucible /
      mass_before_mg / mass_after_mg / batch / notes
```

⚠️ `applied: false` 的样品（未处理参照系）**只填 `not_applied_reason`**，
**不要**填 `mass_before_mg` / `mass_after_mg` —— 会报"自相矛盾"。
加列必须改闭集常量（`PROCESSING_OPTIONAL_FIELDS`），这也是"闭集"的本意。

### A2. 设备型号 + 通道轮转 —— 文档只算了通道·天，没有轮转

文档有「12 颗 ≈ 120 通道·天 ⇒ 8 通道约 15 天、16 通道约 8 天」，但 `轮转` / `设备型号` **0 命中**。

**为什么不可补救**：不同通道的系统偏差会与**样品效应完全混淆**，
跑完只剩"样品 A 比 B 高 3 mV"，**拆不开是材料还是通道**。

**定死的形式**：写明设备型号与通道数；**样品 × 平行按通道轮转**
（每个样品不固定在同一通道），并把轮转表作为附件。

### A3. 静置电压噪声底 `σ_noise` —— 0 命中

**为什么不可补救**：预注册的负对照 **N1**（零激励窗口代价面精确平坦）与"静置是否够长"
都依赖噪声底；**没有 `σ_noise`，这条判据是空的**。而它必须用**空跑**测（Step 0 空跑 30 min）。

**定死的形式**：Step 0 空跑 30 min 静置段，标定 `σ_noise`（mV），写进方案；
判据写成 `max|ΔV| ≤ k·σ_noise` 并给出 `k`。

### A4. 静置结束判据**缺硬上限**

文档有「末端 `dV/dt` < 1 mV/h」（第 108 行）——**判据有了，但没有硬的刹车**。

**为什么不可补救**：判据驱动的静置可能**永不满足**（某些电压区电压线性衰减不收敛），
排期会失控到把整轮实验拖死。

**定死的形式**：`dV/dt < 1 mV/h` **且**不短于 30 min，**同时**给硬上限
（例：最多 5 圈 / 120 h，**先到者为准**），并写明越过硬上限时该段记什么。

### A5. LCA / 能耗 —— **分析可以晚做，但有两个数有窗口期**

文档里 `功率` / `能耗` / `装料` **全部 0 命中**。

**已定（2026-09-19）**：LCA 评价允许往后放。**但这两个数过期就取不回来**：

| 数 | 窗口期 | 后果 |
|---|---|---|
| **炉子程序实录**（实际温度-时间曲线） | 控制器缓冲常被后一次运行覆盖 | 事后只剩"设定程序"，拿不到**实际**曲线；升温速率误差就无从核对 |
| **装料量**（每炉，g） | 事后无物可称 | 与 `mass_before_mg` 合起来才是失重率的**分母** |

**可后补、不构成窗口期的**：额定功率（看铭牌）、功率曲线（额定 × 实测程序推算）、各段气体流量（MFC 设定值）。

⇒ **LCA 分析晚做没问题**；但上面两行必须在**第一次开炉**时落进记录。

### A6. 材料身份确认 —— 缺"证明它确实是石墨"这一步

文档里 `人造` / `天然` / `正极相` **0 命中**；`d002` 只在 XRD 输出里出现 1 次。

**为什么不可补救**：样品 id 的**前缀会骗人**（`CG-*` 看着像 commercial graphite，
实际可能是别的料）；而 `d002` 是**判人造/天然石墨**的判据，XRD 一做完就没法重来
（除非留着样）。料源若混入正极相，整个"石墨"的前提就错了。

**定死的形式**：材料身份一节写三条 —— ① 回**原始文档逐字查证**（不靠文件名）；
② XRD 定石墨类型（`d002` 判人造/天然）；③ **查有无正极相峰**并明确"无"。

## 3. B 类：会被审稿人打回的口径（5 条）

与 §2 的区别：这些**不是补不回**，而是**漏了会被直接打回**，且**必须在看数据之前写死**。

| # | 项 | 现状 | 定死的形式 |
|---|---|---|---|
| B1 | **平行样一致性的统计量** | 只写「先看**原始值**与一致性」（预注册 §3.2 与设计 §7） | 用**相对极差 `(max−min)/mean`**；**同时报三颗原始值**。`n=3` 时 CV 的置信区间极宽，判 5 % 几乎等于没判 |
| B2 | **实验单元（experimental unit）** | `实验单元` **0 命中** | 明确写：单元是**电芯**还是**电极**；技术重复与独立重复**分开报** |
| B3 | **多重比较的层级** | `多重比较` **0 命中**。实际比较数 = 窗口数 × 2 方向 × 样品数（G6.1c 放电扫程就有 **239 个窗口**） | 预登记**唯一主结局**（只有它能支撑结论句）；其余标支持性/探索性；不校正则声明"未做校正"并**报出全部比较数** |
| B4 | **异常值剔除规则** | `异常值` / `剔除` **0 命中** | **`n=3` 不剔除**；异常只由**预登记的硬件/工艺故障**（短路/漏液/温控失控/超硬上限）触发作废；`n≥6` 才用中位数 ± MAD（`|z|>3.5`）并**报出** |
| B5 | **比值型指标的误差传播** | 判据阈值直接给了数（如带宽上限 0.30 dex），没写误差来源 | 给一阶传播式；阈值取 `max(经验值, 2u)`；**`2u` 超限即记「不可判」** |

### 另外一条要你明确选的：τ 阈值口径不一致

| 出处 | 阈值 | 依据 |
|---|---|---|
| 本仓库设计文档第 109 行 | `τ = D·t/R² ≲ 0.1` | 本仓库自己的估计 |
| 开跑前体检技能的实测基准 | `τ ≤ 0.04`（`t_pulse ≤ 0.04 t_d`） | 实测偏差 5 % 出现在 `t_pulse/t_d ≈ 3×10⁻²`；**`> 0.04 t_d` 即失效** |

两者差 **2.5×**。而 §3.2 已经算出：R_p 13.70 µm + 600 s 脉冲 ⇒
x=0.02 **τ=2.37**、x=0.10 **τ=0.98**、x≥0.30 才降到 0.128 以下。
⇒ **按 0.1 判，只有中段可用；按 0.04 判，可用区间还要再窄一截。**
**这不是文字问题**：它决定"GITT 到底覆盖哪些 SOC 段"，而且**必须在开跑前定**
（定了才能决定要不要在稀相端加一组**短脉冲**档）。
