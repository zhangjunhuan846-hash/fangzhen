# 平台的"自动匹配"到底是什么（给导师汇报用）

> 一句话：**输入"实验数据 + 材料信息表"，平台自动把数据规范化，并按规则表匹配一个
> 与之兼容的 PyBaMM 参数集，然后跑 zero-fit 仿真、给出误差评价和完整溯源。**
> 匹配的是**模型参数集**，不是"别人的实验数据"。

---

## 1. 输入是什么

| 输入 | 内容 |
|---|---|
| 实验数据 | CSV/Excel/Maccor/BioLogic 导出（时间、电流、电压、容量、温度…） |
| 材料信息表 | `dataset_info.xlsx`（16 个字段）：数据集名、样品编号、正极化学体系、电池构型、工作电极、对电极、标称容量、面容量、极片面积、电压上下限、温度、初始 SOC、电流符号约定… |

平台只读这两样，**不需要改代码**。

## 2. 平台自动做的事

```
实验数据 + 材料信息表
        ↓
① 格式统一（canonical：time_s/current_A/voltage_V/capacity_Ah/temperature…）
        ↓
② 12 项数据校验（严重/警告分级，出 validation_report.html）
        ↓
③ 按规则表匹配参数集（依据：化学体系 + 电池构型 + 工作电极 + 对电极 + 面容量）
        ↓
④ zero-fit baseline 仿真（不做任何参数拟合）
        ↓
⑤ 误差评价 + 结果溯源（run_metadata.json / dataset_manifest.json）
```

## 3. 当前规则表覆盖范围（真实情况）

| 声明组合 | 匹配到的参数集 | 等级 | 含义 |
|---|---|---|---|
| LFP + 全电池 | `Prada2013` | **B** | 化学体系兼容，但非用你的电池标定 |
| NMC + 全电池 | `Chen2020` | **B** | NMC811/石墨，容量与几何不同 |
| NMC + 半电池（工作电极=正极，对电极=锂金属，面容量 2.0 ± 0.2 mAh/cm²） | `Jackowska2025_2mAh_cm2` | **B**（电极设计尺度匹配） | 与参数集作者同一电极体系，但仍非你的批次 |
| **石墨 + 半电池（工作电极=负极，对电极=锂金属）** | **暂无** | — | **尚未注册，会明确报 SIMULATION = NOT AVAILABLE** |
| 其他任何组合 | 无 | — | 明确拒绝，**绝不偷换参数集** |

关键设计：**匹配不上时不硬凑**。平台会打印
`DATA IMPORT = PASS / SIMULATION = NOT AVAILABLE` 并说明原因，
而不是随便找个参数集跑出一个好看的结果。这是可以拿来讲的严谨性。

## 4. 平台**不**做的事（避免过度承诺）

| 不做 | 说明 |
|---|---|
| 不做数据检索 | **不会**自动去网上/文献里找"同样材料的实验数据" |
| 不做语义理解 | 不从"石墨"两个字自动推导参数；需要化学体系/构型/电极/面容量等显式字段 |
| 不做参数拟合（baseline 阶段） | zero-fit 是设计原则；拟合必须是**单独立项 + 参数锁文件**的新阶段 |
| 不跨体系外推 | 没有匹配参数集就是没有，不会用近似体系凑 |

## 5. 汇报时的准确说法

> "平台做的是**数据规范化 + 参数集自动匹配 + zero-fit 仿真与误差评价**。
> 我填入实验数据和材料/电极信息后，平台自动判断该用哪个 PyBaMM 参数集，
> 并强制标注匹配等级和来源；如果找不到兼容参数集，它会明确说不提供仿真，
> 而不是随便套一个。目前覆盖 LFP、NMC 全电池和 NMC 半电池，
> **石墨半电池的参数集条目我正在加**。"

不要说：

> ~~"输入材料就自动匹配一样材料的数据"~~ —— 平台不检索别人的数据，
> 匹配的是模型参数集，依据是你声明的那几个字段。

## 6. 石墨半电池的落地方式（待你确认）

PyBaMM 自带 `Ecker2015_graphite_halfcell`（含 Li 金属对电极动力学 Xu2019），
可作为石墨半电池的兼容参数集：

| 项 | 建议 |
|---|---|
| 规则表条目 | 化学体系 = 石墨，构型 = 半电池，工作电极 = 负极，对电极 = 锂金属 |
| 匹配等级 | **B**（compatible_surrogate）——同化学体系，不是你的石墨/批次 |
| 面容量 | 记录并报告，但**不像 Jackowska 那样设硬约束**（该参数集非按特定面容量标定） |
| 需要改的地方 | `user_tools/spec.py`：ALLOWED_CHEMISTRY 增 `graphite`；PARAMETER_SUPPORT 增条目；对应校验与报告文案 |

确认后即可落地，全部为 additive 改动，`battery_sim/` 科学核心不动。
