# Gate 5.3 — $D_s$–$R_p$ 联合辨识几何与失配补偿

> **结论：放开 $R_p$ 不能修复失配，只是把失配藏进数据本来就约束不住的那个方向。**
>
> 完整因果链（三步都是实测）：
>
> ```text
> ① 电压曲线主要约束 τ_d = R_p²/D_s
>      → control 二维 cost 谷沿 iso-τ_d 方向（角度 1.96°/3.16°，伸长率 3.2）
> ② 失配时优化器正是沿这个"浅方向"滑动来吸收误差
>      → Δz_D = +1.12 而 2Δz_R = +1.17（iso-τ_d 要求 2Δz_R = Δz_D，几乎精确吻合）
>      → τ_d 只变 +12 %，而 D_s 变了 1200 %、R_p 变了 280 %（并撞上界）
> ③ 残差下降 52–92 %，所以失配"看起来被修好了"
> ```
>
> 运行命令：`python scripts/identification/g5_3_joint_identifiability.py`（约 652 s）
> 报告 JSON：`outputs/fitting/g5.3/g5_3_report.json`（gitignored）

`particle_radius` 在进入联合辨识前必须自证可用：

| 条件 | 结果 |
|---|---|
| 存在于参数集 | `Positive particle radius [m]` = **5.22e-6 m**（float）✓ |

**顺带否掉一个朴素预期**：若"曲线只认 $\tau_d$"，则沿 iso-τ_d 移动应当无响应。
实测同一 $\tau_d$ 的两端符号相反、差别很大：

| | $R_p$ +20 % | $D_s$ ×1.44（同 $\tau_d$） |
|---|---|---|
| SPM 0.1C | −2.88 mV | **+1.90 mV** |
| SPM 0.5C | −13.23 mV | **+8.95 mV** |

→ $R_p$ 不只进 $\tau_d$，还进比表面积（$a=3\epsilon/R$）与通量边界条件，
所以**并非严格退化**。但下面的二维图会给出更准确的几何。

## 1. CONTROL：二维 cost 谷的形状（SPM → SPM）

`z_D = log10 D_s`、`z_R = log10 R_p`，15×15 粗扫 + 15×15 细化，分辨率 **0.0107 dex**。

| 倍率 | argmin $(z_D,z_R)$ | 真值 | 伸长率 | **与 iso-τ_d 夹角** | 判定 |
|---|---|---|---|---|---|
| C10 (0.1C) | (−14.6990, −5.2823) | (−14.6990, −5.2823) | **3.22** | **3.16°** | **ridge ALONG iso-τ_d** |
| C2 (0.5C) | (−14.6990, −5.2823) | (−14.6990, −5.2823) | **3.25** | **1.96°** | **ridge ALONG iso-τ_d** |

**两个倍率的 argmin 都精确落在真值上**（分辨率 0.0107 dex 内），所以控制臂是干净的。

**但谷是"脊"不是"碗"**：伸长率 ~3.2，主轴与 iso-τ_d 方向夹角仅 **2–3°**。

> **读法**：一条电压曲线**主要**约束 $\tau_d=R_p^2/D_s$。
> $D_s$ 与 $R_p$ **不是完全退化**（垂直方向曲率非零，故最小值唯一），
> 但沿 iso-τ_d 方向明显更浅 —— 那个方向上的组合对曲线几乎等价。

**这一步是前提**：后面 §2 的补偿之所以能发生，正是因为存在这条浅方向。

## 2. MISMATCH：$\theta=\{D_s\}$ vs $\theta=\{D_s,R_p\}$（SPMe → SPM）

| 倍率 | 单参数 RMS | 双参数 RMS | 残差下降 | 双参数 $D_s$ | 双参数 $R_p$ |
|---|---|---|---|---|---|
| C10 (0.1C) | 1.656 mV | **0.480 mV** | **−71.0 %** | 2.63e-14（**+1215 %**） | 2.000e-05（+283 %，**撞上界**） |
| C2 (0.5C) | 7.011 mV | **3.389 mV** | **−51.7 %** | 2.33e-14（**+1065 %**） | 1.886e-05（+261 %） |

**残差大幅下降 —— 表面上看是"多一个参数把失配修好了"。**

### 但看 $\tau_d$ 就不一样了

$$\tau_d^{\text{truth}} = \frac{(5.22\times10^{-6})^2}{2.0\times10^{-15}} = 13624\ \mathrm{s}$$

| 倍率 | 双参数 $\tau_d$ | $\tau_d$ 变化 | $\Delta z_D$ | $2\Delta z_R$ |
|---|---|---|---|---|
| C10 | 15204 s | **+11.6 %** | **+1.1191** | **+1.1667** |
| C2 | 15259 s | **+12.0 %** | **+1.0664** | **+1.1156** |

iso-τ_d 的条件是 $2\Delta z_R = \Delta z_D$。实测两列**几乎精确吻合**。

> **优化器几乎完全沿着 iso-τ_d 方向滑动**：
> $D_s$ 变了 **11–13 倍**、$R_p$ 变了 **3.6–3.8 倍**，
> 而 $\tau_d$ 只变了 **12 %**。

**所以这不是"两个参数各自被确定"，而是"一个组合被确定、另一个组合自由漂移"。**
0.1C 时 $R_p$ 甚至**直接撞到 20 µm 上界** —— 这是失控补偿的典型特征，不是物理答案。

### 结果分类：**A，且通过 C 的机制实现**

| 情形 | 判定 |
|---|---|
| A 残差明显下降、参数大幅偏离 | **✓ 成立**（残差 −52 % ~ −71 %，参数偏 1000 %+） |
| B 残差几乎不下降 | ✗ |
| C 很多组合都有类似残差 | **✓ 机制成立** —— §1 证明存在这样一条浅方向，§2 证明优化器正是沿它滑 |

**所以答案是：放开 $R_p$ 不解决失配，只是把失配藏进数据本身约束不住的方向。**
"多一个参数"降低残差这件事，在这里**恰好是问题而不是进步**。

## 3. PROFILE：是"平坦"，还是"残差大"？（补 G5.2 缺的证据）

G5.2 曾把 1.5C 的 92.6 mV 地板解释为"$D_s$ 失去杠杆作用"。
**该解释已用直接测量检验，结论是"部分成立，但原表述过强"。**

以 **profile 自身的最小值**为基准（不是以真值为基准 —— 失配下真值本就不是最小值）：

| 倍率 | profile 最小值位置 | 真值是最小值？ | ±0.05 dex 引起的 J 抬升 |
|---|---|---|---|
| C10 (0.1C) | **−0.10 dex** | ✗ | **×3.447** |
| C2 (0.5C) | **−0.10 dex** | ✗ | **×3.024** |
| 1p5C (1.5C) | **0.00 dex** | **✓** | **×1.466** |

**两条结论**：

1. **曲率确实在高倍率下减弱，但远未"塌陷"。**
   1.5C 的 ×1.466 是 0.1C 的 ×3.447 的 **42 %**（弱 2.4 倍），
   但"移动 0.05 dex 让 J 涨 47 %"仍是一个明确的最小值。
   → 正确表述：**high-rate sensitivity is reduced (~2.4×), not collapsed.**

2. **两个独立方法在偏差方向上一致**（这是一个有力的内部校验）：

   | 倍率 | 单参数优化器给出的偏差 | profile 最小值位置 |
   |---|---|---|
   | 0.1C | −25.01 %（$z=-0.125$） | −0.10 dex |
   | 0.5C | −27.65 %（$z=-0.141$） | −0.10 dex |
   | 1.5C | −0.35 %（$z=-0.002$） | 0.00 dex |

   优化器与显式扫描**独立地**给出同向、同量级的偏差，且都指出 1.5C 偏差极小。

**教训（写进方法学）**：
> **残差地板大，只证明失配大；不证明目标函数平坦。**
> 前者是**残差**的性质，后者是**曲率**的性质 —— 必须分别测量。

## 3b. 高倍率延伸（G5.3.1 / G5.3.2）—— **答案是「情况 A」，而且比低倍率更强**

初版只测了 0.1C / 0.5C。**"高倍率会不会打破 $D_s$–$R_p$ 退化"决定了整篇方法论文讲哪个故事**，
所以补跑 1C 与 1.5C：

```bash
python scripts/identification/g5_3_joint_identifiability.py \
    --rates 1C,1p5C --out outputs/fitting/g5.3_highrate      # 约 534 s
```

### 四个倍率的完整对照

| 倍率 | **Control 伸长率** | **与 iso-τ_d 夹角** | Mismatch 单参数 RMS | 双参数 RMS | 残差下降 | 双参数 $D_s$ | 双参数 $R_p$ | **$\tau_d$ 变化** |
|---|---|---|---|---|---|---|---|---|
| 0.1C | 3.22 | 3.16° | 1.656 mV | 0.480 mV | −91.6 % | +1215 % | +283 %（**撞界**） | +11.60 % |
| 0.5C | 3.25 | 1.96° | 7.011 mV | 3.389 mV | −76.6 % | +1065 % | +261 % | +12.00 % |
| **1C** | **5.17** | **0.77°** | 33.020 mV | 13.104 mV | −84.3 % | +1244 % | +283 %（**撞界**） | +9.20 % |
| **1.5C** | **11.01** | 1.09° | 92.568 mV | 47.440 mV | −73.7 % | +1364 % | +283 %（**撞界**） | **+0.28 %** |

### 结论：谷**不旋转、不收窄 —— 而是变得更狭长**

```text
伸长率   3.22 → 3.25 →  5.17 → 11.01        （单调增长，1.5C 是 0.1C 的 3.4 倍）
夹角     3.16° → 1.96° → 0.77° → 1.09°       （始终 ≤ 3.2°，即始终贴着 iso-τ_d）
```

**高倍率不但没有打破退化，反而强化了它。**

第二条独立证据（profile，沿 $z_D$ 的纯方向）方向一致：

| 倍率 | ±0.05 dex 引起的 J 抬升 | profile 最小值位置 |
|---|---|---|
| 0.1C | ×3.447 | −0.10 dex |
| 0.5C | ×3.024 | −0.10 dex |
| 1C | ×1.884 | **−0.05 dex** |
| 1.5C | ×1.466 | 0.00 dex |

**$D_s$ 的曲率随倍率单调变弱（×3.45 → ×1.47，弱 2.35 倍）。**

两条测量为什么一致：iso-τ_d 方向是 $(\Delta z_D,\Delta z_R)=(2,1)/\sqrt5$，
**本身就 89 % 落在 $z_D$ 上** —— 所以沿 $z_D$ 的纯方向移动，也主要在沿那条长脊滑。
脊越长，纯 $z_D$ 方向的抬升就越小。**两个观测量在同一条物理事实上互相印证。**

### 一个极干净的观察

**1.5C 的双参数最优点：$\tau_d$ 只变 +0.28 %**，而 $D_s$ 变了 **+1364 %**、$R_p$ 变了 **+283 %**。

即在 1.5C 上，$(D_s\times14.6,\;R_p\times3.83)$ 这一对组合，**对电压曲线而言几乎与真值不可区分** ——
哪怕反演用的是结构错误的 SPM。**这就是"有效时间尺度"取代"物理参数"的最纯粹形态。**

**而且 1C 与 1.5C 的 $R_p$ 都精确停在同一个上界 `2.00000e-05`** ——
优化器若被允许会走得更远。这说明该"解"是**边界产物**，不是物理答案。

### 这对实验设计的含义（直接决定 G5.4）

```text
情况 A（高倍率仍 iso-τ_d）  →  ✓ 实测成立，且更强
情况 B（高倍率打破退化）    →  ✗
```

→ **在这四个倍率上做 multi-protocol 联合辨识，预期收益很小** ——
因为四档的脊几乎同向（夹角都 ≤ 3.2°），**脊的交集不会显著收窄**。
真要用倍率解耦，需要的是能**旋转脊方向**的条件，而不是"更多相同机理的曲线"。

**真正独立的额外信息是**：

- **直接测量的粒径分布**（用户手上已有 D10/D50/D90 = **10.72 / 17.58 / 27.82 µm**）
  —— 把 $R_p$ 从"待辨识"变成"已知"，退化当场消失
- 或**显著不同的机理区间**（更低的倍率，让扩散不再是限制步骤；
  或脉冲类工况 GITT，其时间常数与恒流放电不同）

**所以下一步（G5.4）应当设计成 multi-protocol identifiability 的检验，
并且要带着"这四个倍率可能不够"的先验去做** —— 而不是期待多倍率自动解决问题。

## 4. 这一关的结论

$$\boxed{\text{parameters become identifiable} \;\neqq\; \text{they became meaningful}}$$

- **G5.2**：错误模型下，偏掉的参数**优于真值**，低倍率无残差信号
- **G5.3**：放开第二个参数**不会修复**它 —— 反而因为数据只在 $\tau_d$ 方向上有约束，
  额外自由度被用来**沿那条浅方向逃逸**，把残差降下去而参数彻底失去意义

### 措辞（重要，不要写成"不可辨识"）

**不要说** "证明 $D_s$ 与 $R_p$ 不可辨识" / "structural non-identifiability" —— **太绝对**。
本文的结果**不支持**这个说法，因为 §0 已经实测：**同一 $\tau_d$ 并不完全等价**
（两端响应符号相反，差 4.8 mV @0.1C / 22 mV @0.5C）。

严谨表述应为：

> **Under single-rate voltage fitting, $D_s$ and $R_p$ exhibit strong practical
> correlation dominated by the diffusion timescale, while additional protocols
> are required to improve parameter separability.**

即：这是 **practical identifiability limitation**（工程上受限、可用实验设计缓解），
**不是 structural non-identifiability**（模型本身不可区分、再多数据也没用）。

### 方法学含义

1. 判"能不能辨识"不能只看**残差下降**，必须看**参数是否落在数据能约束的子空间里**。
2. $\theta=\{D_s,R_p\}$ 在**单条曲线**下不宜作为独立的辨识目标 ——
   需要能打破 $\tau_d$ 退化的额外信息（不同倍率、不同颗粒尺寸、
   或**直接测量的粒径分布**：用户手上已有 D10/D50/D90 = 10.72/17.58/27.82 µm）。
3. 上界撞墙（0.1C 的 $R_p=20$ µm）**应当被当作失败信号上报**，
   而不是当作一个"拟合到边界的最优解"。

## 5. 边界（必须一起引用）

- **仍是合成数据**。换掉的是**模型形式**，不是数据来源；真实实验还有别的不确定度。
- **四个倍率全部测过**（0.1C / 0.5C / 1C / 1.5C）—— 这是 chen2020 能提供的全部。
  所以"倍率能否打破退化"这个问题的答案，在这份数据上已经用尽了可用的倍率。
- 只测了**一个失配方向**（SPMe → SPM）；反方向未测。
- 单电芯（cell 02）、单参数集（Chen2020）。
- **谷的伸长率 3.2 属于"中等脊"**，不是极端退化；垂直方向曲率非零，
  所以严格说是**部分退化**而非完全不可辨识。用词需谨慎。
- $R_p$ 的上界（20 µm）是**我自己设的**。0.1C 的解撞到它，
  说明真解可能在界外 —— 这本身也说明该配置下 $R_p$ 的上界选择需要重新考虑。

## 6. 下一步（G5.4 应据此设计）

**"倍率能否打破退化"已回答：不能，而且更强**（§3b）。
所以 G5.4 不应期待"多倍率自动解决"，而应设计成
**multi-protocol identifiability** 的检验，并带上明确先验：

| 待做 | 目的 |
|---|---|
| **多 protocol 联合辨识 + confidence ellipse** | 四档脊方向接近，量化**交集究竟收窄多少**（预期收益小，需实测确认） |
| **把 $R_p$ 当已知**（用实测 D10/D50/D90 = 10.72/17.58/27.82 µm） | 退化**当场消失**，$\theta=\{D_s\}$ 回到良定义问题 |
| **反向失配**（SPM 生成 → SPMe 反演）与 DFN 上界 | 判断偏移的方向性，给出 model-form error 的量级上界 |
| **G5.4 真实数据** | 先用"能否旋转脊方向"筛 protocol，再决定辨识几个参数 |

**判据不应是 RMSE**，而应是：参数相关性 $\mathrm{corr}(D_s,R_p)$、
Hessian 条件数、confidence interval、profile likelihood。

```text
one protocol   →  parameter ridge
multiple protocols  →  ridge intersection  →  identifiable parameters
```

**若脊方向在所有可用 protocol 下都相同**（本关的实测倾向），
则交集收窄有限 —— 此时**唯一可靠的出路是独立测量的 $R_p$**，而不是更多曲线。
