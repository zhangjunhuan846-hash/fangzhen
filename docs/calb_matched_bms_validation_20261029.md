# CALB 同电芯脉冲、EIS 与驾驶回放验证

## 数据和状态对应

数据来源：[CALB L148N58A testing campaign V2](https://doi.org/10.17632/ycx459r5c3.2)，CC BY 4.0；[数据论文](https://doi.org/10.1016/j.dib.2025.111301)。作者对 11 个 58 Ah B 级方形电芯，在 10、25、40°C 标称箱温下做 C/20、HPPC、驾驶循环和 EIS。此次下载 8 个电芯的三个温度、各 8 组处理后 `.mat` 文件，共 192 个；按发布方 SHA-256 核验，清单位于 `data/public/calb_matched_v2`、`calb_matched_extra_v2` 和 `calb_matched_extra2_v2`。每个 MAT 记录按电芯编号与温度配对，不能当成 192 个独立电芯。

作者的协议先进行慢速放电和 HPPC，再进行驾驶循环，EIS 在驾驶序列之后。这里用每个电芯自己的 C/20 和 HPPC 1C 脉冲拟合容量、OCV 近似及 RC 网格，后续独立 HPPC C/3 脉冲和驾驶记录用于评分；逐文件的 EIS 只审计和建目录，没有把较晚 EIS 当成先前驾驶回放的已知校准。25°C 有的 EIS 文件只有 3 条谱，目录保留实际数量，不补造缺谱。文件夹标记的 HPPC 电流大小由原始电流筛选核对；其中开发读取中发现一个相同时间戳，保留该时刻最后一条并记录；时间倒退直接报错。

这些记录对应同一编号、同一温度测试批次与已知先后顺序，但本次没有独立复测每次试验之间的 SOH，不能断言所有测量的内部状态完全相同。

## 比较方法和边界

- 固定 RC：在每个窗口开始时按该电芯、标称温度和初始估计 SOC 查一次已测 HPPC 表，此后参数固定；对比方法在窗口内按自身 SOC 估计继续查表。两者使用相同的同电芯标定、初态和测量噪声。窗口内网格不允许外推。
- 匹配使用的是温度**设定点**；实测表面温度在窗口内可能变化，本次没有证明表面温度动态补偿效果。每个被测电芯都提供了自己的先前 C/20 / HPPC，因此是新电芯上的**同电芯已校准**验证，不是无需新电芯校准的跨电芯零样本迁移。
- 驾驶 SOC 参考为该电芯该温度 C/20 电压曲线推算驾驶起点，然后积分驾驶电流并除以测得容量。脉冲参考以 HPPC 开始满充为锚点再积分。两者均是 SOC 代理，有初始锚点、极化、滞回及容量误差，并非直接 SOC 真值。
- 每个窗口人为将滤波器初始 SOC 设置为代理值减 4 个百分点，且 RC 初始极化为零，这是受控恢复测试，不能当作未知初态的完整 BMS 精度。驾驶每个窗口长 600 秒，按活动记录时长的 20% 和 60% 起始；每个窗口分别算 RMSE 后等权平均。不同窗口并非独立电芯。
- **单步电压**为当前电压输入滤波器前的预测，允许使用之前电压；**开环电压**在给定窗口初始化后不读取实测电压。两种指标不可互换；开环仍依赖近似 SOC 起点和已测电流。

## 固定与查表的独立电芯比较

最初 4 个电芯已参与开发或上一轮评估；接着用它们选择固定 RC、普通查表和包含 RC 对 SOC 导数的 EKF 候选。电压优先的开发集选择为固定 RC。然后在此前驾驶信号未评分的 60129、60403 两个电芯上进行测试：36 个驾驶窗口、3 个温度、3 类驾驶工况。固定 RC 与普通查表的 EKF 单步电压平均 RMSE 分别为 **4.224 / 4.228 mV**，SOC 代理 RMSE 分别为 **2.198 / 2.191 个百分点**；开环电压分别为 **18.178 / 18.179 mV**。雅可比候选也没有稳定优于固定 RC；并且该候选只改变 EKF，UKF 仍使用原有近似。

详情见 `outputs/eis_bms_validation/calb_fresh_cells_20261029/`。这批测试电芯在下面的后续噪声选择中转为开发电芯，不能再次称为全新测试。

## 再次调参和新留出电芯

在已观察的六个电芯上，以 108 个开发驾驶窗口比较 SOC 每步过程方差 `1e-10、1e-8、1e-7、1e-6`，在单步电压误差不超过原值 110% 的条件下选择 SOC 代理误差最小者；选择为 `1e-10`。电压噪声 `0.005 V` 在之前的开发记录上选定，且固定 RC 的选择沿用上一轮。选择结果在解析新测试驾驶信号前写入 `calb_pretest_freeze.json`；校验文件哈希会先读取原始字节，但不解析信号。

在新留出的 60644、60710 两个电芯、3 个温度和 3 个驾驶循环共 36 个窗口，结果为：

| 方法 | EKF SOC 代理 RMSE | EKF 单步电压 RMSE | 开环电压 RMSE |
|---|---:|---:|---:|
| 固定 RC，原过程方差 `1e-8` | 2.261 个百分点 | 3.623 mV | 17.244 mV |
| 固定 RC，开发选择 `1e-10` | 2.236 个百分点 | 3.721 mV | 17.244 mV |
| 查表 RC，开发选择 `1e-10` | 2.238 个百分点 | 3.727 mV | 17.240 mV |

调参使 SOC **代理**指标小幅下降，同时单步电压变差；改善幅度很小，不能证明实际 SOC 精度提高，也不能据此推广为所有电芯的默认噪声。查表方法在本实验中没有清晰优势，工作站保留固定 RC 的默认值。新的 `soc_process_variance_per_step` 可在配置中指定，表示每一步的方差；这里使用 1 秒采样，换采样周期不能直接沿用该数值。

对相同两电芯的独立 HPPC C/3 脉冲，在接近 30%、50%、70% SOC 代理位置、三个温度选取 18 个 120 秒窗口。原固定 RC 与调参查表的 EKF 单步电压 RMSE 为 **4.157 / 4.152 mV**，开环 RMSE 为 **29.853 / 29.853 mV**。每个窗口人工设置 4 个百分点初态偏差，因此开环值包含初始 SOC 偏差的影响；不能归因于 RC 参数本身。选择参数后曾先检查 60644、25°C 的一条 C/3 谱对应脉冲窗口，未据此调整参数；完整驾驶测试运行后已按同一冻结方法复现。

## 工作站使用与复现

工程任务中选择“CALB多电芯脉冲与驾驶回放验证”，直接运行，不需上传 CSV；输出逐窗口、逐点、C/3 脉冲指标、EIS 清单及标定与划分 JSON。EIS 网格桥接的 `filter_rc_mode` 仍默认为 `fixed`；`estimated_grid` 与试验性 `estimated_grid_jacobian` 可用于同电芯已通过筛查的参数表。两种模式都应在自己的时域数据上重新验证。

```text
python user_tools/fetch_calb_matched.py
python user_tools/fetch_calb_matched.py --extra
python user_tools/fetch_calb_matched.py --extra2
wsl -e /home/zjh/.local/share/fangzhen/engineering/bin/python -m pytest tests/test_calb_validation.py tests/test_engineering_eis_grid.py tests/test_engineering.py -q
```

实验划分和公式口径见 `configs/calb_bms_protocol_v3_20261029.json`；结果存放于 `outputs/eis_bms_validation/calb_final_20261029/`。后续需要无初值辅助、覆盖完整循环的独立 SOC 基准，以及同电芯匹配时序的 EIS→脉冲→驾驶验证，才能判断查表和调参是否在实际 BMS 中改善估计。
