# 资源预算对照：运行前方案

2026-10-14。本轮测试当前平台策略，不实现或验证专利草案C3，不预设任何方法获胜。

数据：本地Mendeley 10.17632/4dh2h3tsf4.1 的 ASC 工作簿；复用现有只读解析器和质量排除规则。同工艺条件的电芯聚合为条件均值，INK标识保留。D5协议尚未确认为1C，数据是普通石墨电极制造，不是自有回收石墨。

固定配置：50个回放种子；每种子共同随机初始5个条件；总预算12单位，包括初始设计。每个条件最多查询一次。所有方法只能看到已揭示的标签及候选已知工艺、成本；未测标签只由评测器持有。推荐与输入哈希先写入文件，再揭示标签。重复种子反映这个有限候选池的策略/初始化变化，不是50次独立材料实验。

七种策略：随机；预设maximin空间填充DOE；固定描述符GP的plug-in EI；同一EI除以已知条件成本；固定描述符GP的UCB；观测数据上Spearman选3项的GP-EI；同样动态描述符的GP-UCB。GP复用工作站固定核、5%相对噪声近似。EI不是原版qNEI，成本EI不是HVKG。固定/动态同采集函数对照才能讨论描述符作用。DOE只代表有限历史候选空间的空间填充设计，不代表全部DOE理论或正交设计。

三个预先规定成本场景：每条件1单位（相同条件次数）；未辊压1、辊压1.5单位（假设额外辊压资源）；根据候选ID和固定盐20261014哈希确定1、1.5或2单位（与标签独立的已知成本敏感性）。后两者是相对成本假设，不是元、电费、实际机时或LCA。不同算法在同种子/场景的成本表和总预算相同。无足够余量时停止；不追加预算。

主要比较：固定和动态GP-EI在预算末的最佳历史D5差；固定/动态UCB作对应消融。补充比较各策略相对随机、成本EI相对相同GP-EI。报均值、种子标准差、配对差、配对bootstrap 95%区间、胜/平/负次数；区间只刻画当前候选池的初始化不确定性，未作多重比较校正，不作为跨材料显著性证据。

辅助演示阈值预先固定为D5≥360 mAh/g，仅测试达标统计，不是实际再生验收目标。首次发现历史均值达标的累计成本；初始5项作为一次共同设计，初始已有达标时计初始全额成本。未达标单独标为右删失；另报在12单位预算截断的首次达标成本，未达标按预算上限计，区别实际支出。没有独立新重复验证，不能叫“经重复确认的首次达标”。

对GP方法记录预测均值≥阈值但历史均值未达阈值的比例，名称为“均值判达标误判”；同时可报告未校准GP后验概率≥0.9的诊断，不能把它当已校准可信推荐。随机/DOE无此预测宣称，记不适用，不能记零误推荐。缺失ICE/收率不虚构标签，本轮不评估三目标合格率。

预算过程记录最佳D5、累计相对成本、已观测ID/数量及本次预测。任何拟合失败写明并使主运行失败，不静默切成随机。原数据和旧回放结果不修改。保存源码/配置/Excel哈希、逐步决策、原始CSV、图和报告。
