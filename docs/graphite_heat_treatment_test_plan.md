# 热处理梯度石墨样品 → 平台：实验设计与记录清单

> 场景：把一批石墨分 3 组处理（干燥 / 500 °C / 800 °C 管式炉），测电化学性能，
> 想用规格书那份商用石墨当参照。
>
> 本文只做一件事：**让这批数据做完就能进平台**，而不是做完发现少了一组对照、
> 或者某组没跑倍率而补不回来。

---

## 0. 一个必须先说清的歧义

"把这个分 3 组"里的"这个"是哪一种，**对照组的定义完全不同**：

| 读法 | 3 组是什么 | 必须补的对照 |
|---|---|---|
| **A. 你的回收/待处理石墨** | 同一批料的 3 个处理温度 | **商用石墨**（规格书那批）作为参照系，同批次做半电池 |
| **B. 商用石墨本身** | 同一批商用石墨的 3 个温度 | **未处理（as-received）组**，否则分不清"干燥"相对"什么都没做"的效应 |

**两种读法都指向同一件事：你列的 3 组不够，至少要 4 组。**
"处理有没有用"这个判断，靠的从来不是处理组之间的比较，而是**处理组 vs 未处理对照**。

下面的清单两部分都适用，只在第 2 节标出差异。

---

## 1. 现在就要定的 4 件事（做完就补不回来）

### ① 对照组
见上。**规格书不能替代对照**——那是厂商在别人的设备、别人的装配工艺下测的，
和你的极片/电芯之间隔着装配变量。

### ② 每组 ≥3 颗平行电芯
不是形式主义。平台的整套逻辑是**参数辨识**，而**没有平行样，任何参数都给不出误差棒**。
单颗电芯的差异里，材料差异和装配差异是混在一起的，事后无法分离。

### ③ 气氛与升温程序必须记全
500 °C vs 800 °C 的结论**几乎完全由气氛决定**：

| 气氛 | 500–800 °C 下发生什么 | 预期 |
|---|---|---|
| 惰性（Ar / N₂） | 石墨基本稳定，主要是**去表面官能团、去除无定形残碳** | 质量损失小，缺陷修复有限 |
| 含微量 O₂ | 石墨开始**氧化烧失**，比表面可能先升后降 | 质量损失大，性能多半变差 |
| 含 H₂（还原性） | 还原表面氧物种 | 与惰性组不同 |

要记：**气氛与流量 / 升温速率 / 保温时间 / 降温方式 / 装样量 / 处理前后质量**。
处理前后质量差直接量化"去掉了多少 SEI、无定形碳、官能团"——这是 500 vs 800
差异的**第一手证据**，也是最便宜的一条。

### ④ 哪一组做辨识、哪几组留作验证

**这是审稿人第一个会问的问题，而且是唯一做完就补不回来的决定。**

平台的 `governance/dataset_roles.py` 就是为这件事建的：数据集必须声明
`identification` / `validation` / `benchmark` / `prediction`，**拿验证集去标定直接报错**。

建议：

- **1 组做辨识**（跑 p-OCV + GITT，用来提参数）
- **其余组只做验证**（只跑倍率，参数绝不回头调）
- 这样"处理温度 → 参数变化 → 倍率表现"是一条**完整因果链**；
  而"每组各自拟合出参数、再看谁好"是**三份互不相干的曲线拟合**，不构成验证。

⚠️ 这条必须现在定，因为它决定**哪几组要跑倍率**。倍率是平台目前唯一缺的一环，
一旦某组漏了，事后补不了。

## 2. 最小实验矩阵

机时估计基于本项目已跑过的 SINTEF 协议（脉冲 1800 s + 静置 9000 s；
p-OCV 循环约 100 h），**数量级参考，不是承诺**。

| 组 | 处理 | 电芯 | p-OCV | GITT | **倍率** | EIS | 角色 |
|---|---|---|---|---|---|---|---|
| **G0**（对照） | 未处理 / 商用石墨 | ≥3 | ✓ | ✓ | ✓ | 可选 | **identification** |
| G1 | 干燥 | ≥3 | ✓ | ✗ | ✓ | 可选 | validation |
| G2 | 500 °C | ≥3 | ✓ | ✗ | ✓ | 可选 | validation |
| G3 | 800 °C | ≥3 | ✓ | ✗ | ✓ | 可选 | validation |

**几个刻意的取舍：**

- **p-OCV 每组都做**：单循环约 4 天/颗，便宜，而且每组拿到**自己的实测 OCP**——
  热处理会改变表面状态，OCP 曲线本来就该变，这是最直接的证据。
- **GITT 只做 1 组**：GITT 约 **1000 个脉冲 × 3 h ≈ 4 个月/颗**。
  而本项目 B1/B1.6 已经证明：这份数据上单颗粒反演出的 apparent D_s
  **比参考低 1–2 个数量级、且不能改善回放**（两种拟合形式结论一致）。
  **花 4 个月 × 4 组去换一个已知不可用的参数，不值。**
- **倍率每组都做，且是重点**：这是"预测 → 验证"闭环唯一缺的一环，也是唯一能
  检验"处理温度有没有用"的判据。建议至少 C/20、C/10、C/5、C/2、1C 五档。
- **EIS 可选**：平台**完全没有 EIS 通路**（无代码无数据）。要做就得先决定
  是否把它纳入论文范围；不做就明确划掉，别含糊。

## 3. 必须记录的字段

### 材料侧（处理前后各测一次）
- D10 / D50 / D90（**处理前后都要** —— 见第 5 节）、BET
- 处理前：原始质量；处理后：质量 → **损失率 %**
- 气氛、流量、升温速率、保温时间、降温方式、装样量

### 电化学侧
- 首圈容量（mAh/g，**按活性物质质量归一**）、**首效 %**
- 每组载荷量（mg/cm²）、极片厚度、压实密度、直径
- 电解液、隔膜、对电极、装配环境（手套箱水氧值）
- 温度（室温是否实测，还是"声明"）

> 平台必须拿到**载荷量、厚度、面积、活性分数**才能算容量一致化
> （`Q_model` 必须等于 OCP 表的 SOC 锚点），否则回放会系统性跑偏——
> 这一步在本项目里曾经让 RMSE 从 91.86 mV 降到 6.27 mV。

## 4. 数据怎么进平台（建议：**3–4 个数据集条目，不是 3 个 cell**）

**为什么不是"1 个数据集 + 3 个 cell"**：平台的 `dataset_role` 目前是
**数据集级 / 倍率级**的，**没有 cell 这一维**。如果 4 组塞进一个数据集，
就无法声明"G0 是辨识集、G1–G3 是验证集"——而那正是这批实验的核心设计。

**推荐做法**：

```
configs/datasets.yaml
  graphite_ht_untreated:   { adapter: graphite_ht, raw_dir: ..., dataset_role: identification }
  graphite_ht_dry:         { adapter: graphite_ht, raw_dir: ..., dataset_role: validation }
  graphite_ht_500:         { adapter: graphite_ht, raw_dir: ..., dataset_role: validation }
  graphite_ht_800:         { adapter: graphite_ht, raw_dir: ..., dataset_role: validation }
```

- **一个 adapter 文件**（`battery_sim/datasets/graphite_ht.py`）服务 4 个条目——
  registry 按 `adapter` 字段解析类，各条目自己的 `raw_dir` 由 config 传入。
- 4 个条目 = 4 份数据集，但共用同一套化学体系与构型，差异只在处理工艺；
  工艺写进各条目的 `dataset_role_note` 与 metadata。
- 每组的 `dataset_role_note` 写明处理条件，这样"为什么这组是验证集"是可审计的。

（`governance/` 的门会在有人拿 validation 组去提参数时直接报错。）

## 5. 已知的坑（都是本项目踩过的）

| 坑 | 后果 | 对策 |
|---|---|---|
| **粒径变化被读成材料改善** | 回收/处理石墨的"容量恢复"常常来自破碎、细粉，而不是本征改善。而平台里 **D ∝ R²**，粒径差异会被直接读成扩散系数差异 | **处理前后都测粒径**，并在报告里把"粒径效应"与"本征改善"分开 |
| 用 BET 反推粒径 | BET 2.62 m²/g 按球形等效直径只有 **≈1.0 µm**，比 D50（17.58 µm）小 **17×** | **不要用 BET 推 R**。BET 主要来自内部/边缘表面 |
| 拿实测首圈容量去"校正" c_max | `c_max` 是**理论结构量**（Ecker 31920 mol/m³ ≈ 378 mAh/g，满锂化 LiC₆）；348.9 mAh/g 是**实际**容量 | 直接比是范畴错误。两者分别作为"上限"和"QC 指标"用 |
| 用振实密度当极片孔隙率 | TD 1.02 g/cm³ 是**粉体**振实密度 | 孔隙率要由压实后极片密度与真密度算：`ε = 1 − ρ_极片/ρ_true` |
| 单颗电芯下结论 | 参数没有误差棒 | 每组 ≥3 颗 |
| 规格书当对照 | 厂商设备/工艺与你的不同 | 商用石墨**同批次做半电池**才是对照 |

## 6. 验收带（规格书数值的正确用法）

规格书给的是**材料级验收带**，不是模型参数：

| 指标 | 规格 | 实测 | 用途 |
|---|---|---|---|
| D10 / D50 / D90 | 11.0±2 / 17.0±2 / 28.0±3 µm | 10.72 / 17.58 / 27.82 | **QC**：处理后的粒径是否仍在这条带内 |
| BET | 2.5±0.2 m²/g | 2.62 | QC |
| TD | 1.0±0.1 g/cm³ | 1.02 | QC |
| 首次可逆容量 | ≥340.0 mAh/g | 348.9 | QC + **对照** |
| 首次效率 | ≥92.0 % | 93.3 | QC |

**用法**：你的 4 组测出来若**落不进带里**，先怀疑**装配/化成/气氛**，
而不是先怀疑模型。这个"先排除实验"的顺序能省掉大量争论。

## 7. 平台侧现状与缺口

| 需要 | 平台现状 |
|---|---|
| 半电池 p-OCV → OCP 提取 | ✅ 现成（`extraction/ocp_extractor.py` + B0/B0.6） |
| 容量一致化 | ✅ 现成（需要载荷量/厚度/面积/活性分数） |
| GITT → D_s | ⚠️ 通路完整，但**这份数据上已证明不可用** |
| **倍率验证** | ✅ 仿真侧现成，**缺的是实验数据** |
| EIS → k0/Rct | ❌ **完全没有**（无代码无数据） |
| 降解量（首效损失） | ❌ runner 不输出 SOC/浓度/降解量 |
| 用途治理 | ✅ 现成（`governance/`），可直接给 4 组分配角色 |

---

## 8. 一句话总结

**你要做的不是"3 组处理样品的电化学测试"，而是"1 个对照 + 3 个处理梯度的
受控扰动实验"**——对照组决定结论能不能成立，倍率决定结论能不能被检验，
而 GITT 在这份材料上大概率不值得花 4 个月。

先定第 1 节的 4 件事，再动手。
