# 电荷一致性联合诊断：最小验证协议

目标：判断时间尺度、电流符号与容量重置的联合诊断是否有实用增量。不是专利新颖性证明，不接入工作站自动修复，不改变旧预处理行为。

主要主张：在给定列单位和计数器语义正确的条件下，利用时间戳、稳定电流段的电荷积分和充/放容量增量，能够识别候选时间尺度和电流极性；缺证据、互相矛盾或时间回跳时拒绝输出可自动应用的完整方案。

输入限定：明确单位的电流A、充放容量Ah、原始相对时间与可选时间戳/步骤状态。不推断任意仪器、未知容量单位、通道异步、缺采样期间电流、无参考时间的回跳修复。不以电压升降判电流符号。输出规范为“充电为正”，不是PyBaMM电流约定；半电池嵌脱锂方向也不在本轮推断。

候选：相对时间乘数{1,0.001,60,3600}，电流极性{+1,-1}。容量重置只在明确步骤边界的负跳变处标记；不拼接为全局累计容量，不把重置跳变积分成物理电量。没有负跳变时只能说“未观测到重置”，不能证明全局累计。

预先固定规则：仅比较同一步骤内、时间递增、两端电流稳定且非零、容量增量充分的区间；电流稳定容差5%，电荷比中位数误差5%、90分位25%；时钟比中位数误差2%；充放符号一致比例至少98%；证据至少10个区间。有不明计数器负跳变或原始时间非递增时，不允许完整方案自动应用。不同候选均通过时保留歧义。

基线：旧normalize_csv（表头单位+时间戳告警）、时间戳单证据、容量积分单证据；所有基线获得相同原始字段，单证据基线仅作为消融，不冒充最强现有方法。

数据：三份现有公开仪器文件均为开发检查（以前已使用），发布者元数据和文件哈希留档。公开文件不能验证所有符号/重置修复。规则固定后合成验证种子1000–1099，每种情况100条独立序列：正常、毫秒、分钟、反符号、毫秒+反符号、容量逐步重置、组合重置、缺证据、时钟与电量冲突、时间回跳。额外稳定电流缺失/无方向等失败边界用单元检查；没有查看结果后再选种子。

合成真值：独立生成分段恒流和已知充放电量，含非电流边缘的缺采样、有限噪声和量化；真值单独存放，不传给诊断器。只用同段稳定区间积分，不验证复杂CV/异步工况。每条独立合成轨迹是统计单位，不能把行数当样本数。

成功条件：可识别的合成情形中至少95%输出正确完整方案，无错误自动应用；预设冲突、回跳和缺证据情形无错误自动应用。报告拒绝率、字段级结果、完整方案正确率、误修率以及各场景独立实例二项比例Wilson区间。原型未通过则报告失败，不修改规则直到本次结果保存。

独立核验：合成真值由解析分段电量生成；验证程序对输出时间尺度与电流极性查真值，并检查接受轨迹的重建电量。保留所有失败、拒绝、原始合成数据和候选证据。本轮不宣称论文贡献、专利创造性或真实材料收益。
