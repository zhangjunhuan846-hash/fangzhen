# 仿真诊断与参数探索

入口：启动科研工作站 → 仿真与结果 → 仿真诊断与参数探索。

启动脚本在本机优先打开 `outputs/fangzhen_workbench_ui_v0310_ready/FangzhenResearch/FangzhenResearch.exe`；源码仓库没有打包版时会改用 Python 入口。默认数据使用 `data/workbench_scalar10`；首次打开复制旧版工作站数据和作业到新目录并保存升级前备份。启动时会核对当前服务版本，避免旧版窗口接管新版入口。

借鉴来源：[Battery-Sim-Agent](https://github.com/opqrst-chen/Battery-Sim-Agent)，作者仓库提供的论文 DOI：10.1145/3770855.3818856。参考其“仿真反馈→参数建议→历史记忆→再次仿真”的结构；本项目重新实现接口，没有复制上游代码或整电池提示词经验规则。上游 MIT 许可；若后续复制源码需保留其版权与许可声明。

## 本次实现

- 两个真实公开数据入口：SINTEF石墨半电池pOCV-deli，以及Chen2020全电池C10。
- 复用现有 `_run_one_replay` 和数据用途治理；验证/预测用途不得反向用于标定。
- 只探索扩散系数与交换电流密度的原函数倍率，保留浓度/温度依赖；两种案例均调整positive槽位。石墨案例positive为石墨工作电极，Chen案例positive为正极材料。
- 几何、载量、OCP、初始状态与其他参数保持原参数集/数据适配器的固定值。没有利用用户样品记录补全未知参数。
- 倍率边界由使用者声明，允许0.01–100倍且包含1倍。预算3–20次，包含初始回放；始终保留最优已覆盖候选。
- 比较窗口预先固定为观测时间范围的前98%，所有候选使用同一组观测点。未覆盖窗口的模拟判失败，不能靠缩短曲线取得低误差。
- 分早、中、晚三个时间阶段记录RMSE及偏差；差异描述不作为唯一机理归因。
- 每轮参数、理由、误差/失败状态写入memory.json；各轮保留curve.csv与diagnostic.json。任务输出包含数据SHA256、代码SHA256及PyBaMM版本。
- 默认规则策略是围绕当前最佳候选的坐标探索。可选LLM根据指标和历史生成JSON建议；越界、额外参数、重复建议或接口失败会停止。两种策略可在相同预算下分别运行并比较。

## 可选LLM配置

工作站“仿真与结果”→“仿真诊断与参数探索”下展开“模型API地址与端口”，填写基础地址（含端口）、模型名和可选密钥，然后点击“保存本机配置”。“检查接口”会读取模型列表，不发送实验数据；实际参数建议需运行LLM策略任务验证。也可在项目目录手动创建 `data/agent_llm.local.json`：

```json
{
  "base_url": "http://localhost:11434/v1",
  "model": "你的模型名称",
  "api_key": ""
}
```

远程接口需HTTPS，本机允许HTTP。该文件已加入.gitignore；密钥不写入任务输入或记忆。“检查接口”从Windows进程连接 `/models`；参数建议从WSL进程连接 `/chat/completions`。若模型服务只监听Windows的 `127.0.0.1`，WSL可能无法用同一地址连接；此时需让服务在WSL中运行或提供WSL可达的地址。以实际LLM任务验收连通性。

界面选择LLM后，需要勾选发送公开案例的参数历史与诊断指标。不会发送工作站的用户样品表，也不上传原始曲线图片。无需密钥时直接选规则策略。

## 验收解释

规则搜索、LLM建议均只能生成有效候选。当前没有为Agent实现参数唯一性判定或独立留出验证，不能把探索最低误差当作材料验证通过。原有Chen2020参数辨识/留出预测入口继续独立保留。当前Agent入口尚不对用户上传曲线做自动拟合。

可运行 `python -m pytest tests/test_battery_agent.py` 验证边界、失败排除、预算、记忆和任务接入；真实仿真必须在既有WSL PyBaMM环境执行。
